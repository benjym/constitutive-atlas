## Search sequence and stopping rules

1. Search the existing source cache and release documentation first: report tables, equipment, preparation, sensor lists and processing scripts. This recovered substantial Ottawa information without acquiring more experiments.
2. Trace a workbook citation to the original thesis and experimental publication. Match specimen labels, state timing, pressure, density and strain definition together. A matching pressure or visually similar curve is insufficient to establish identity.
3. Look for original numerical channels and documented apparatus transformations. Preserve the published graph as evidence when necessary, but record digitization provenance and uncertainty separately. Do not reconstruct a volume history from a reported peak dilation angle.
4. If public documentation remains insufficient, record a precise unanswered question and retain a qualified task or exclude the affected comparison. Do not resolve the ambiguity by whichever assumption gives the best model prediction. No author contact has been made.

The [prepared clarification questions](dataset_clarification_questions.json) name exact report tables, specimen groups, source files and conflicting values. They are ready for a future enquiry; none have been sent. Repeated searches of the same unavailable Heron repository will not recover its thesis. Further public-source work should follow a specific new document, release revision or accessible thesis, rather than repeat the same queries.
