# Prospective evidence source closures

For every new numerical study, select explicit source roots and suffixes with `atlas.evidence_sources.selected_files`. The helper excludes hidden trees, __pycache__ and bytecode regardless of requested suffixes, rejects path traversal and rejects selected symlink files. Do not add ambient build output/cache trees to the source list. Explicitly include the harness, assessor, protocol, literal requests, independent references, relevant tests, compiler/headers and expected generated outputs.

Hash the exact chosen bytes and retain a complete source snapshot before compiled observations. Bind build/toolchain receipts and raw journals to that freeze. Reconstruct the held source closure in a fresh temporary tree and reproduce protocol/generation or assessment without ambient repository sources. Distinguish replayed numerical gates from actual artifact hashes, compiled execution and scientific admission. Retain failures and source-accuracy gates unchanged.

This helper is for new studies. Never regenerate a historical freeze or change its pinned hashes to remove an incidental cache. Preserve such bytes as opaque evidence and document a separate isolated replay/repair identity. Existing studies use their own historical source choosers; do not silently migrate them. The normalized-determinant expression study is the first shared-helper consumer; the prior primitive's existing cache-free chooser remains frozen.

The selector is a source inventory utility, not a sandbox or a complete dependency detector. Callers must inspect actual imports/includes/generated dependencies and root/suffix choices. A passing hash/replay check proves the declared closure, not that all scientific/model requirements have been met.
