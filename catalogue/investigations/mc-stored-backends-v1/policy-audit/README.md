## Branch eligibility and visible arithmetic

Intervals follow the actual gap-based v2 classifier expression order, including rounding after each basic operation. Canonical K/G receive relative gamma8 envelopes; canonical sin/cos receive absolute4eps envelopes. These are explicit checked implementation contracts, not portable C++ libm theorems. Material coefficients actually emitted by the driver must lie inside them. If the backend cannot meet them, the prospective study fails and retains that finding.

Trial stress is propagated from exact stored parent/loading using coefficient intervals. General eigenvalue intervals add the inherited primitive512eps*norm allowance plus trial perturbation/Weyl radius. Diagonal coordinate sorting gives tighter component bounds. Ordered interval comparisons enumerate feasible paths through elastic/apex/face/left/right with the actual strict/non-strict inequalities. Dependencies are conservatively lost, so sets can overapproximate feasible branches. They are not an oracle proving every enumerated branch can occur.

Require this to match emitted branch, then require membership in the frozen eligible set. A successful branch must have a defined canonical fixed-branch reference. Never search all five references for the closest answer. Undefined selected repeated-spectrum alternatives cannot supply a tangent reference.

## Proposed prospective accuracy contract

For each selected eligible defined branch, table budgets are Mandel Euclidean/Frobenius norms:

- value residual error <=32768eps*S*(1+n/g)+2minsub;
- each of38 residual derivative vector errors <=262144eps*D_j*(1+n/g)^2+2minsub.

Here S is frozen reference stress_scale, D_j its direction_scale, n the exact canonical trial Frobenius norm, and g the selected minimum gap. For elastic/apex set the whole condition factor to1. Constants are declared engineering acceptance contracts, not a derived worst-case theorem. They deliberately expose poor conditioning. Print budget/natural-scale ratios; if a ratio exceeds1%, label that comparison resolution-limited and do not cite it as useful relative accuracy. Tight component requirements below still apply. Parent may adopt stricter gates before compilation; do not change these constants after observing failure under this identity.

The six current-only basis columns must be exactly the identity, all other return dependence on current exactly zero. Off-parent current requests change residual by the exact rational stored-current difference; return and all derivatives remain unchanged. Use Fraction for this shift, not a subtract/add round trip. Parameters are double-only in generated code: this study's38 columns cover current/parent/loading, and the five scientific parameter sensitivities in the reference are not tested production parameter Jets.

For all3 `mixed-scale-middle/*` diagonal open-face cases additionally require absolute middle residual error <=128eps*abs(reference middle)+2minsub and exactly zero off-diagonal residuals. This protects middle1 beside1e300 and middle1e-300 beside1e-100, which a norm-only gate would miss. Do not use max(1,...) for that gate.

## Failure witnesses and coverage

Required-success rows may not fail. Conditional rows may fail only with an actual documented witness and matching generated failure site:

1. Selected ordinary spectral operation failed and the actual selected raw eigenvalue gap is <=1024eps*actual trial Frobenius norm (include decode/scaling error if the emitted trial norm is unavailable). This is numerical rejection, not a source restriction. Exact complementary repeats alone are not a witness.
2. Actual selected face/left/right multiplier is negative at the corresponding domain check; append these three actual derived scalars to trace to make the witness reviewable.
3. Actual coefficient-domain endpoint or nonrepresentable intermediate/derivative has a pinned source-site witness and a predeclared source-range enclosure. The present table does not pre-authorize arbitrary range failures; absent that enclosure the row is unresolved/failing, not accepted.

The checked spectral wrapper currently exposes bool only, so failure_line alone does not distinguish selected-gap failure from a decomposition failure. A source threshold witness plus the exact selected-operation failure site is the minimum bounded acceptance claim; it does not prove that internal cause. If actual diagnostic classification is required, expose diagnostic status through write-only study instrumentation before freezing. Do not infer status from the desired result.

Nonfinite inputs/seeds and9 invalid material/numerical parameters must reject, return empty evaluation output, preserve all input bits, then allow independent recovery. Failure output scratch is discarded; no transactional scratch-preservation claim is made.

## Initialization, solver and transaction requirements

Direct residual and host solver are different interfaces. Source admissibility applies to the accepted initial parent for integrate; a free current Newton iterate is independent. Explicit initialization tests must cover validzero, inadmissible tensile hydro current with check_initial=true rejection, the identical current with check_initial=false success, and solver inadmissible parent rejection. The numerical initial/postreturn yield allowance is256eps*max(h,abs(extrema)); it does not alter the raw Ftrial<=0 classifier. `domain()` evaluates the zero-load return too, so parent admissibility alone does not prove its entire numerical evaluation will succeed.

Solver-source successes need independent initial-parent admissibility and ordinary finite numerical evaluation; do not assume every source certificate is a valid accepted parent without checking. Their output error must include residual tolerance: per component add2e-10*p_ref to the return-value budget (Mandel norm allowance sqrt(6) times that term). This is a solver tolerance allowance, not a change to source stress accuracy. Require no subdivision under max_depth0, finite state, and honest diagnostic counts.

Actual rollback: establish a successful accepted baseline, force max_iterations1/max_depth0 on a nonzero source update, show implicit_step produced a changed tentative vector but failed, then integrate must fail with rejected>=1 and message prefix `integration failed`, return the original accepted6stress bits, and leave committed6stress bits unchanged. Recovery and fresh calls must both independently succeed and both full vectors equal the independently known zero-hold state. Compare full states, not merely booleans or agreement with each other. Early nonfinite/invalid-parameter rejections are separate tests and do not prove tentative-update rollback. This MC law has no reset/history state; do not add synthetic history claims.
