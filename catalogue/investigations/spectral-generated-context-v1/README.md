# Generated spectral contexts v1

Prospective synthetic arithmetic study of the installed spectral DSL. This is not a constitutive model or scientific admission.

The 1,589 requests cover emitted expressions, actual generated residuals and physical-time observables, lazy/eager/sticky controls, domains, initialization, check-only, scales, reset values, generated history transactions and actual solver failure/recovery. Jet contexts use all 38 incoming columns. History, scales and solver contexts are double-only.

Independent p360 stored-Mandel references and unchanged primitive error bounds are copied in reference/. Assessor source review and corruption probes are in assessor/. Both backends must pass those same independent bounds; bitwise backend equality is not required. Expected failures preserve caller inputs and accepted history/solver state; scratch output may mutate and must be discarded. The solver failure occurs after a tentative memory reset; no time rollback claim is made.

The complete input closure is frozen in prospective-freeze.json before any compiled observations. execute.py verifies it before and after each separate configure/build/run phase, captures commands and logs, and refuses overwriting an existing phase. Native and Wasm builds run serially with one explicit target and --parallel 1; Wasm also sets EMCC_CORES=1. Failed attempts are retained. Backend assessment reports are separate post-observation evidence.

Source-generation failures and exact copied-source generator replay are retained. See policy.json, wire.json, slots.json and assessor/README.md for the precise contract and limitations.
