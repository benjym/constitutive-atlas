## Build and identity evidence

Native Apple Clang21 and Emscripten6.0.8 builds ran sequentially, each with one
explicit `atlas_isolated` target and `--parallel 1`. Wasm additionally used
EMCC_CORES=1. Both generated headers and descriptors match byte-for-byte. Build
receipts retain toolchain/configure/build commands, logs, statuses and exact
artifact hashes; raw C-ABI/stream output is retained before assessment.

The first native receipt script failed after successful compilation because it
expected a list rather than the generated catalogue object's `models` field.
Its script/failure are retained. Recovery verified the existing generated bytes
and completed the receipt without recompilation or any rate call beforehand.
One unused `check_initial` generated-parameter compiler warning is retained.
