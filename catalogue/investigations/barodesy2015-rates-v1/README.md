## Execution contract

`cmake/research`, separately for native and Wasm. Retain actual configure/build
commands, stdout/stderr/status, toolchain versions, generated descriptor/header

`prospective-freeze.json` records this design. Raw observations, build receipts,
assessments and results are additive files. Failed outcomes remain preserved;
no case deletion or post-observation tolerance adjustment is permitted. Any
engine repair needs a separate source identity and a distinct follow-up study.

Reproduce the design with `python3 -B prepare.py --check` from this directory.

preserve or explicitly archive those bytes, rather than pretending the original
study was run on the new implementation.
