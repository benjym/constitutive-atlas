# Clay2005 boundary parity diagnostic v1 — prospective design

This separate diagnostic tests the hypothesis raised by the [failed original v3 study](../clay2005-rates-v3/RESULTS.md): implicit contraction of arithmetic operations may cause native/Wasm differences in the cancellation-sensitive near-singular source rates. It changes only the compilation flag `-ffp-contract=off`, on both newly built backends. It changes no model, input, source vector, support classification or numerical/parity budget. All109ordered requests and their complete expectations are preserved.

Before any diagnostic build/rate execution, `prospective-freeze.json` pins this plan, protocol, scripts and expected generated bytes. The protocol pins the original source/build closure, failed comparison and diagnostic source/flags. Raw journals are retained in new paths. Builds remain serial, one explicit target and --parallel1/EMCC_CORES1. Original v3 artifacts, failed assessment, references and raw output are immutable.

Prospective comparisons: (1) re-audit the original failed result and prove the exact109case identity; (2) evaluate both new backends against the original numerical/support/rejection/recovery/parity gates; (3) compare each new decoded response with the corresponding original same-backend response, reporting all changed values and the maximum scaled change; (4) inspect the new native assembly for fused multiply/add/subtract instructions and retain command/artifact/output identity. Complete-control echoes, subnormal material rejection and persistent recovery remain required.

If the original gate passes with contraction disabled, that demonstrates this compiler choice is sufficient to remove the observed difference for this matrix/toolchain. It does not prove the boundary rates accurate, establish that fusion is universally undesirable, or authorize a global production flag change. Independent actual-input precision/conditioning assessment is a separate parallel source study. No source budget is newly assigned to finite-only cases.

Any remaining failure is retained. Next implementation decisions require both contraction and independent precision evidence. No public candidate, laboratory preview, general numerical support/accuracy, tangent, experimental or scientific admission claim follows from this diagnostic.
