# Solver transaction study v1 — prospective protocol

Seven synthetic engine-conformance fixtures use schema v0.3 with full explicit formulation/input contracts. Existing-record migration is untouched. Models were migrated from the independently prepared solver-rollback-design-v1 packet; original models and eleven-row/three-preparation expectations are retained there. Effective stress is an explicit synthetic fixture choice (stress=sigma, no pore pressure), not a claim about external constitutive sources. The complete expected.json bytes match the independent design.

Acceptance is frozen before compiled observation: exact ordered complete eleven API rows, original committed-state/time binary64 bits, exact accepted substep counts, bitwise unchanged inputs, all-invalid scale vectors, plus three low-level preparation witnesses. An intentionally failed reset value leaves its final scratch slot unspecified as declared before observation; the first successful write and returned committed state are exact. Both backends must independently pass and match completely, except that unspecified failed-value scratch has no cross-backend gate. No gate is revised after observation. The assessor additionally distinguishes bool from integer and rejects duplicate JSON keys.

Actual production integrate, integrate_time and run_schedule are called. Late timed failure is specified to occur after four accepted internal substeps; success under the same settings takes eight. Observable scales are tested via schedule, which consumes them. Source changes are not part of this study. All transitive C++ headers plus generator, validator and schemas are snapshotted in frozen/; build uses frozen headers and the retained generated models.hpp. All builds are serial, explicit-target, single-job. The original independent design and its source-only failure remain in docs/reviews/solver-rollback-design-v1.

Scope: this bounded double-precision solver/reset/scale transaction corpus. No constitutive equation accuracy, experimental fit, nonlinear stress-control convergence, general history-program rollback or scientific admission claim.
