# Frozen generated-context contract

The protocol contains1,719material calls and18history calls per backend. All55synthetic model records use schema0.3 with explicit formulation and initialization. Observable fixtures use physical-time ODE/no stress binding and finite stage time0; other fixtures use fixed-frame strain-path rates. Loading is zero; this is generated-expression conformance, not material stepping.

Nine contexts are covered: equation, derived expression, domain, initial check, observable, increment-reset guard, increment-reset value, state scale and observable scale. Variants are direct determinant, predicate, eager zero masking, both lazy arms and outer trace composition. A separate trace-first/determinant composition uses exact diagonal cancellation and all38seed columns.

Eight generated paths (equation/derived/observable/reset-value, each direct and outer-trace) preserve every one of the78independent primitive fixtures and their exact input/seed literals. No oracle is computed by Atlas. Accepted scalar bits and38derivative bits come directly from those independently certified references. For each predicate context except parameter-only scales, every one of38Jet columns receives an isolated invalid seed. Finite overflow and recovery cover all contexts/variants. Initial-check disabling, check-only skipping and observable-only execution are separately specified. Parameter-only scale overflow must return the compiler's nonfinite failure sentinel, interpreted by the harness as failed finite scales.

The material harness supplies an explicit13component input vector: zero stress, six A components, zero scalar b. It records the scalar b output (or sole observable/last scale), all38scalar derivatives when applicable, exact compiled model ID/catalogue hash, complete input bit immutability, output count and finiteness of every successful output. It does not claim oracle checks of unrelated tensor output values. Failed model outputs remain scratch and are neither inspected nor promised atomic. The low-level core's separate atomic-output study is unchanged.

There are670explicit immediate material rejection/recovery pairs and sixhistory good/bad/recover triplets. Each recovery must exactly reproduce its earlier full response apart from request ID. History checks include original-parent retention, output scalar, generation, epoch, events and failed phase. Model/seed inputs intentionally containing NaN or infinity are fixture strings; parser conversion reaches the actual generated path. They are not JSON numeric constants or parser-rejection evidence. History overflow uses finite inputs.

Acceptance is exact closed response shape, exact status/type/value bits, all applicable derivative bits and complete decoded native/Wasm parity. There is no error tolerance. Literal ordinal request controls bind raw journals to the frozen case tables; actual compiled model/program identities bind dispatch to the generated descriptor. Before any build or execution, source/reference/harness/cases/expectations/generated bytes are hash-frozen and copied to frozen/. Ordinary Release flags apply; builds run serially with one explicit target and --parallel1/EMCC_CORES1. Retain failed commands/raw results without changing gates.

The standard-library interpreter and native/Wasm toolchain remain external with command receipts. This is not an exhaustive compiler proof or a constitutive law, integration, experimental validation, performance benchmark or scientific admission. A complete source-preserving clay2005 candidate study remains a separate next task.
