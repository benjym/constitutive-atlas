# Prospective generated expression-context study v1

Acceptance frozen before compilation. 64 synthetic schema v0.3 model records and six separately versioned history programs generate10870 material rows and18 history rows per backend. Each backend must match every complete typed row and binary64 value/derivative bit string, in order, and the complete backend journals must match. Failed evaluations have unspecified scratch output; only status and unchanged inputs are claimed there. Scale vectors must be entirely NaN after executed failures; NaN payloads are deliberately normalized to the string nan and are not compared. No gates change after observed results.

Routes: equations, eagerly evaluated unused derived fields, domain, enabled/disabled initial checks, observable evaluation and its normal/check-only skips, reset guards/values, parameter-only state/observable scales. Generic overflow masks include eager min, predicates, reciprocal and exp of overflowed dot products, lazy true/false branches, and norm of a finite dev result. Predicate routes independently poison all six tensor components ×38 derivative columns ×NaN/+Inf/-Inf with immediate recovery. Every derivative column also receives a finite input derivative yielding overflow at a consuming expression. Exact direct-trace cancellation and finite-intermediate-overflow fixtures retain independently specified primal and all38 derivative bits.

The parameter-only dev scale at r=1e308 is the retained witness from trace-generated-context-v1: dev is finite but its norm overflows. It must now reject rather than hiding infinity in a predicate. Both lazy scale arms pass the corresponding unselected overflow. Six generated history programs cover guard, write, checks, lazy selection, dev, and failure after a prepared phase, preserving parent values/counters/events on rejection.

Original trace study reports/fixtures are untouched. This is a distinct follow-up with actual generic arithmetic changes and explicit v0.3 formulation/input contracts. Inputs use the production compiler, not handwritten kernels. Effective stress is an explicit synthetic test choice. Complete generator/validator/schema/header bytes are frozen; native/Wasm builds include frozen headers and retained generated models/history/cases. Only serial single-target single-job builds are authorized. This corpus does not verify source equations, general loading/time-name routes, material tangents, finite solver behavior or scientific admission. The separately frozen solver-rollback-v1 study covers bounded committed transactions.
