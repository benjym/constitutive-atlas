This compressed source-only capsule preserves211 exact project source/data files for four original finite-study verifier contexts. All eleven original test modules execute unchanged in an isolated materialized tree. Family outcomes stay separate: Barodesy isotropic and wider studies retain their original bounded assertions, the original clay2014 path study remains **failed**, and its controlled-resolution follow-up remains **passed** with `original_failed_study_replaced=false`.

Original groups per family: {"barodesy-isotropic": 28, "barodesy-wider": 20, "clay-controlled": 7, "clay-original-failed": 34}. Root test modules delegate historical assertions to this capsule, cached once per test process. The original modules and fixtures remain byte-for-byte inside the capsule; their complete original assertions and mutation tests run. A passing historical replay means those assertions reproduce, including negative findings; it does not approve the original failed material study or test a changed C++ implementation.

The registry binds the original four receipt manifests, their declared source/data pins (including exact selected archive-map objects), capsule and exact adapter stdout. Original sidecars, registered documents and snapshot objects are preserved in the tree. Public-exclusion assertions load the original five public model definitions. The export includes no private paper, Git metadata, native binary or Wasm artifact. Original build hashes are historical values and are not reopened. The adapter forbids subprocess Popen while original assertions execute; synthetic mocked subprocess paths remain part of original tests.

Compression changes storage only: deterministic gzip wraps the exact source/data capsule. The runner checks the compressed digest/size, enforces a96MiB decoded JSON ceiling, validates every decoded member's hash/size/path, materializes fresh paths and checks them again after execution. Total source data remain subject to the64MiB capsule ceiling. The Python interpreter/stdlib are external; this is trusted project Python replay, not a sandbox or cross-platform binary reconstruction.

During assembly, recursively expanding an unrelated provenance manifest encountered a stale document pin in the symmetric-exponential review. That manifest is not executed by these four verifier contexts. Expansion was bounded to the four actual receipt manifests while preserving referenced provenance documents unchanged. No expected hash, original test, numerical gate or original result was refreshed or relaxed.

Current common-engine verification and any new numerical study require their own tests/identities. This packet confers no material AD, experiments, scientific admission or whole-model validation.
