# Validator identity receipts before formulation v0.3

The inventory registers exact original catalogue receipts for the committed model validator in document-bound archive maps. The original validator byte stream is snapshotted once. Original receipt documents, acceptance gates, observations and failures are untouched. Existing map entries, original map references and sibling manifest registrations are retained. Missing/corrupt snapshots or altered original receipt documents reject; archives do not fall back to live sources.

Identity verification does not isolate Python imports or regenerate historical headers. Source-rates, source-reviews, clay2014-rate, finite-tensor and original sand closures separately preserve historical execution. New generated code receives a new study identity. The current validator may evolve independently; the original studies retain their exact source identity.
