# DSL/compiler identity receipts before general expression checks

The inventory registers exact original catalogue receipts for the committed checked-trace Python DSL and compiler in document-bound archive maps. Both original source byte streams are snapshotted once. Original receipt documents, acceptance gates, observations and failures are untouched. Existing map entries, original map references and sibling manifest registrations are retained. Missing/corrupt snapshots or altered original receipt documents reject; archives do not fall back to live sources.

Identity verification does not isolate Python imports or regenerate historical headers. Source-rates, source-reviews, clay2014-rate, finite-tensor and original sand closures separately preserve historical execution. New generated code receives a new study identity. Compiler evolution here adds checks at every executed AST node; the original tensor operator implementation remains unchanged.
