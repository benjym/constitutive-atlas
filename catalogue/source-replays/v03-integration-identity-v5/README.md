Each source hash is resolved from a matching retained snapshot or Git blob, then bound through a document-hashed sidecar. Original receipt documents, numerical reports, outcomes and acceptance bounds are unchanged. Historical snapshots do not claim current implementation compatibility or re-execution. These records close those identity gaps rather than updating original expected hashes. Inventory checks must reject missing/corrupt source or changed original receipt documents.
