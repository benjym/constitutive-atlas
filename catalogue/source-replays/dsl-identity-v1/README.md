# DSL/compiler identity receipts before checked trace contexts

The inventory registers exact original catalogue receipts for the pre-change Python DSL and compiler in document-bound archive maps. Both original source byte streams are snapshotted once. Original receipt documents, acceptance gates, observations and failures are untouched. Existing map entries, original map references and sibling manifest registrations are retained. Missing/corrupt snapshots or altered original receipt documents reject; archives do not fall back to live sources.

Identity verification does not isolate Python imports or regenerate historical headers. Source-rates, source-reviews, clay2014-rate, finite-tensor and original sand closures separately preserve historical execution. New generated code receives a new study identity. Compiler evolution here adds a generic checked-trace helper include; the original tensor operator implementation remains unchanged.
