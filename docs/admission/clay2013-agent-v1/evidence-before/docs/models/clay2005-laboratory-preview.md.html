# Mašín2005 clay — provisional laboratory draft

The [runnable definition](../../models/hypoplastic-clay-2005.json) represents the Appendix C five-parameter base law from [Mašín2005](https://doi.org/10.1002/nag.416), using the [accepted author manuscript](https://web.natur.cuni.cz/uhigug/masin/download/MasinIJNAMG05-pp.pdf), SHA-256 8650dd58a4b5725dc0176ab9cf3a034ed211847b840524254876c2652bdf9ff3. Appendix C Eqs73–85, manuscript pp24–25, supplies the represented law. The reviewed Eq38 unloading bracket is plus; the earlier Atlas minus-reading error and its additive correction remain recorded. Final publisher equivalence is unverified. The later2013 law and intergranular-strain extensions are separate formulations.

The schema v0.3 contract declares compression-positive effective Cauchy stress and infinitesimal strain-path increments in orthonormal Mandel components, a fixed spatial frame and zero spin. Persistent state contains six stresses and void ratio. The common expression language generates all material mathematics; no handwritten model kernel is added. The homogeneous determinant ratio is evaluated from original stored stress with the generic normalized_determinant operation.

The complete 100kPa spherical stress/e=.8 example and source Table I London-clay parameter set are illustrative software inputs. They do not establish a prepared specimen, a universal clay calibration or a Wichtmann fit. The 2005 r parameter is initial Ki/Gi, not the later model's Poisson-like nu. The source reference pressure is1000Pa; p_scale is a numerical scale. Initial state must be explicit; no hidden NCL/SOM projection, OCR interpretation or density reconstruction is performed.
