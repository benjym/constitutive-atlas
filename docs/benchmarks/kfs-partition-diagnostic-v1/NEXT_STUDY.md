# Proposed nested caller partition study

This is a bounded follow-up proposal, not an executed or frozen native study.
Prepare a separate policy/runner/assessor/test freeze before execution. Keep the
failed factorial refinement packet and its thresholds immutable.

1. Use only four affected cases: coarse indices 2, 3, 10, 11 (TMD7/TMD9 under the
   file and alternative calibration-selected vectors), retaining file evaluation
   states, the exact archived executable/model and all parameter values.
2. Pin existing finest predictions and raw process receipts. Their per-segment
   caller counts N come from the 0.00005 limit; every retained noninitial caller point has
   reported `substeps=2`, `rejected=0`. Require the baseline audit before new calls.
3. Freeze two new caller count schedules, 2N and 4N separately for each acquired
   segment. Keep acquisition endpoints/order, initial specimen states and all
   mixed controls unchanged. This provides nested requested caller knots within
   each segment, subject to binary64 roundoff. It does not make internal
   trajectories identical or guarantee rejection-free updates.
4. Implement the count schedule as an explicit replay-driver choice, with no
   model-specific constitutive kernel or changes to the material equations.
   Declare any archived-adapter command overlay before execution. Audit the
   actual modified command and its echoed native step count, not an unmodified
   adapter request. Preserve strict process success/JSON/catalogue/hash gates,
   complete predictions, serial execution and a 30-second total limit per replay.
5. Run at most eight new replays in listed case/count order, with no retry,
   fitting, evaluation-based selection, build or deployment. Stop native work on
   process failure and retain all attempted receipts. If adaptation returns,
   retain the outcome and do not label that sequence rejection-free.
6. Freeze numerical gates before execution: every noninitial caller point must retain
   zero reported rejections and two reported substeps; both adjacent q/volume
   changes must remain within 1% of the already pinned matching calibration
   response shift; second adjacent change must not exceed the first plus the
   existing normalized 1e-12 floor. Report every predicate and any failure.
7. Reconstruct every native command and full prediction offline. Report the
   eight case/channel checks, both adjacent differences, counters and optional
   descriptive observed ratios. Do not infer an asymptotic order from two
   differences or extrapolate a physical error bound.

A pass would support a separately defined rejection-free nested caller regime.
It would not retroactively pass the original failed sequence, prove source/binary
identity, validate the equations independently, create a new common-resolution
six-test panel, settle source e0 values or supply scientific admission. If it
fails, preserve it and reassess whether further numerical work is justified;
do not launch an open-ended increment sweep.
