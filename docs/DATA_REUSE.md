# Wichtmann experimental data: reuse review

Reviewed 30 October 2026 for the original Karlsruhe fine sand TMD1–5 and TMU1–12 archives pinned in [data/sources.json](../data/sources.json).

## Finding

**Public redistribution permission has not been established.** This is an unresolved permission question, not a finding that reuse is prohibited. Do not bundle raw files, normalized measurements or sampled plot data in the repository, website or deployment artifact until an applicable grant is recorded.

The [author's general remarks](https://www.torsten-wichtmann.de/KFSDB-general.htm) describe the database and provide downloads. The [SoilModels dataset page](https://soilmodels.com/karlsruhe-sand-wichtmann/) describes its use for model development, calibration and verification; its [download package page](https://soilmodels.com/download/package-karlsruhe-sand-wichtmann/) provides the dataset. These reviewed pages did not provide an explicit redistribution licence for the two pinned archives. Neither archive contains a README, licence or copyright notice; they contain only the original test files. Availability for download and intended research use do not, by themselves, resolve permission to redistribute a copy on another website.

The associated publications are [Wichtmann & Triantafyllidis (2016), Part I](https://doi.org/10.1007/s11440-015-0402-z) and [Part II](https://doi.org/10.1007/s11440-015-0412-x). A licence attached to a different publication or dataset must not be assumed to cover these archives.

## Selected adoption: licensed compilation

On 30 October 2026 the user authorized using the licensed compilation for public drained overlays, while keeping the original undrained tests local. The selected release is [version 3](https://doi.org/10.4121/086847a6-ba39-4d66-973b-6b93028c7ad8.v3), independently confirmed through the version-specific DataCite record. This is an adoption decision, not a release approval for the original archives.

**Ingestion is blocked on package retrieval.** Repeat requests to the repository website, documented v2 articles endpoint (including version 3), v3 datasets endpoint and alternate `next.data.4tu.nl` host timed out. IPv4 curl and web fetch also failed. The compiler's public website repository contains the release descriptions but no CSV/package copy. No compiled measurements have been downloaded, normalized or enabled in the public build.

Resume with the version-3 package (or its Karlsruhe material CSV and accompanying README): inspect `FILE_INFO` licensing, `SOURCES` and `TEST_PROGRAMME`; pin the exact downloaded file hashes; ingest only the Karlsruhe drained tests. Retain missing values as missing and use the package's compression-positive conventions. Convert percent strains to dimensionless strains and kPa effective stresses to Pa; derive q = axial stress − radial stress and p′ = (axial stress + 2 × radial stress) / 3. Preserve all available observations and their order. Record whether each curve was digitized; do not substitute the separately downloaded original TMD files.

Visible attribution must credit Huan Wang's Sand Triaxial Test Database (2026, version 3), link its version DOI and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), cite Wichtmann & Triantafyllidis (2016) and any further original references supplied in the material file, and identify Atlas's unit/format conversions and derived channels. The existing selector and lazy-loading path can then serve the processed files without a download/upload workflow.

## Current implementation

A built-in experiment selector and a deterministic processed-asset pipeline are implemented. The local review build includes all five drained and twelve undrained tests from the pinned archives. It uses compact column-based JSON for the five plot channels: axial strain, deviator stress, mean effective stress, measured volumetric strain where available, and pore-pressure change where available. All observations and their acquisition order are retained; values are not rounded, interpolated or sampled during packaging. Full archival normalization remains in `atlas/data.py`.

The browser loads one selected test on demand, verifies its SHA-256 and row count against the index, and retains it in session memory. Visible source links and attribution accompany measurements; users do not need to download, extract or upload original files. Local-file comparison remains optional. Selection and visibility do not change simulation settings. A separate **Use initial state & protocol** action applies available initial stress, void ratio and drainage conditions, preserving material constants, amplitude and loading history. Protocol, initial-state and missing-metadata warnings remain visible.

Redistribution of the original Wichtmann archives remains gated by `data/experiment_releases.json`, currently an empty grant registry. Each grant must identify its exact archive SHA-256 and record evidence, date, scope, attribution and public hosting permission. Preview builds use `--preview-experiments` and output to the separate ignored `web/preview/` directory, never the deployment artifact directory. Rebuilding removes stale experiment files.

Separately licensed sources are now admitted through `data/public_sources.json`: OPARA, all ten GEOLAB material workbooks, Finnish clay, rockfills, Castlegate, Hurley 3DXRD and the LEAP 2015/2017/2018/2020/2022 campaigns. The current catalogue has 613 records and 3,582,338 observations. OPARA, GEOLAB, Finnish clay, rockfills, Castlegate and Hurley use repository-declared CC BY 4.0; admitted LEAP campaigns use ODC Attribution 1.0. These records separate normalized triaxial overlays, native series, acquisition blocks, grain populations and test summaries. Licence declarations are preserved in [the survey evidence](data-license-evidence/dataset-survey-license-declarations.json). Original files are checksum-pinned; processed gzip JSON is committed under `data/curated/` and verified during the public build. This does not change the original Wichtmann archive decision above. The browser retains each new test's attribution, source DOI, licence link and conversion notices. See [the survey ledger](dataset-survey-2026-10-30.json) for remaining source and per-test admission work.

Source transformations remain explicit: kPa to Pa, percent strain to dimensionless strain, TMD void ratio interpreted as dimensionless despite the percent header, and TMU pore pressure relative to its first observation. Missing TMU initial void ratio and unmeasured volumetric strain are not invented. Rendering may show fewer measured markers while retaining the full selected record in memory. An overlay is not an experimental validation claim.

## Gate for a future bundled release

1. Obtain an explicit applicable licence or written permission from the relevant rights holder covering hosting/redistribution and transformed or sampled measurements. Contact requires a separate user instruction; no request has been sent.
2. Record the grant's source, date, scope, attribution requirements and any restrictions beside the dataset manifest. Check that it covers the exact archived files and intended public use.
3. Prepare a versioned bundle with original archive/member hashes, transformation version, units, channel warnings and required attribution. Keep data terms distinct from the code's MIT licence.
4. Add a build-time allowlist so only approved dataset revisions enter the public artifact; test that a clean CI build produces the same bundle.
5. Publish selectable bundled tests with visible source/attribution links, keeping local loading available. Update this review and the README to identify the permission actually used.

This review covers the two currently pinned archives. It does not establish reuse terms for the complete sand database, kaolin database or other Wichtmann datasets.

The full 30-candidate pass has admitted 21 candidates. The other nine remain explicit holds: six SoilModels sources lack verified package access or dataset reuse terms; printed-grain and shale file retrieval is blocked by their hosts; 4TU remains paused at the user’s request. Public availability of metadata alone is not used to infer a hosting grant.

The two LEAP 2018 project DOIs explicitly declare ODC-BY 1.0. Earlier checks saw empty rights on the child experiment DOIs and null fields in the project API; those checks did not cover the project DOI declarations. The evidence now records both scopes and response hashes. The 2018 torsion and simple-shear records are publicly hosted with project/experiment citations; they remain native channel series rather than triaxial overlays.

A follow-up review retrieved all 33 standard ExCalibre workbooks (208 measurement worksheets). Their original hashes and sheet inventories are recorded in [the workbook review](data-license-evidence/excalibre-workbook-review.json). No dataset reuse statement was found in the workbook cells, notes, comments or other XML text. The linked SoilModels terms apply the GPL default to software, so these measurements remain outside the public release pending applicable data terms. The Dryad shale README excerpt is readable through the browser preview; the original workbooks remain unavailable through the download routes tried.
