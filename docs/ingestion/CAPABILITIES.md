# Capability follow-up from parallel ingestion

The [three reviewed packets](README.md) expose distinct integration requirements. This ledger schedules generic work; it does not resolve source contradictions or authorize a guessed canonical law. Read the packet equation/branch locators before implementing any item.

| ID | Source-backed requirement | Existing support / next concrete gate |
| --- | --- | --- |
| CAP-CYCLE | HCA evolves with cycle count N and has resolved-cycle, recording and accumulation phases. Recorder anchors, selected indices, amplitude identity, companion state and count must share a transaction. | Physical-time and strain-path contracts do not establish a cycle-count protocol. Specify a separate driver-owned record/phase contract and replay fixture before compiler changes. Preserve original samples and name the filter variant. |
| CAP-POLARIZATION | HCA literal full-nine-space initializer differs from a symmetric-six-space restriction. A 22-coordinate block representation is closed only under the packet's stated initialization/amplitude/update assumptions. | Select the source/operator variant first. A separately named supplied-amplitude fragment can then prove packing, metrics and angle branches against full9 Cartesian references. Do not raise state capacity or add general fourth/eighth-order arrays solely from discovery. |
| CAP-PLANE-HOST | PM4Silt uses in-plane mean stress and lagged four-subzone/zone operations, with different displayed volumetric/deviatoric conventions. | Current generic symmetric state is Mandel3D. Define a source-consistent dimensional/sign adapter and host reduction before reuse; do not substitute trace/3 or call a homogeneous project reduction the original FLAC algorithm. |
| CAP-LAGGED-PHASES | PM4Silt loading reads old D/Kp/G/K, while later averaged history determines next-step coefficients and reset anchors. | Existing rollback is a foundation. A precise old/new dependency DAG and equality/penalty policy are prerequisites for a generic phased-update extension. Failure must restore zone, subzones, coefficients and mode flags atomically. |
| CAP-ISA-HOST | ISA modifies host density factors and evolves h,c,Z and accumulated strain from one stage. N is undefined at h=c; current-rate/image normalization and boundary entry need explicit policies. | Existing lazy select and symmetric contractions help, but do not settle the source branches. Start with a named supplied-host instantaneous fragment only after its y_h/host variant is explicit. No new fourth-order primitive is justified by N_hyp*(N:D) alone. |
| CAP-INITIALIZATION | All three sources distinguish preparation/phase/history from ordinary material continuation; a missing internal state is not a physical zero. | Require complete state and variant/preparation identity for each bounded study. Keep reset/default/mode events explicit, and test restart and failure recovery before experimental comparisons. |

A future schema version should identify the evolution coordinate (strain-path, physical time or cycle count), required input history, branch/domain semantics, staged/lagged dependencies, preparation and full transaction ownership. Each supported claim needs an executable generic contract and an independent witness. This ledger is a requirement inventory, not evidence that those extensions already exist.
