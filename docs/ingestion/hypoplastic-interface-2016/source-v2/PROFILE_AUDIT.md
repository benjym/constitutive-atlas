# Reading-profile handoff

[profile-draft.json](profile-draft.json) is a source-backed reading-only draft supplied under the public-profile contract. It includes no executable instructions, presets or default values. The empty parameter guide is intentional pending a frozen formulation and calibration context. The integration owner alone edits shared web data.

Existing entry `hypoplastic-interface-2016` in `web/model-profile-data.mjs` correctly describes granular sliding and normal/shear coupling, says no public interface laboratory, uses an empty parameter guide and links the original DOI. Those conceptual statements remain supported by thesis Chapter5, the publisher's identity/abstract, the original source record and this source packet. The entry must not suggest all hypoplastic host variants, arbitrary local frame transport or an approved runnable constitutive law.

Its generic parameter note currently says “Laboratory presets illustrate behaviour.” No interface laboratory/preset is available. The coordinator can remove that generic sentence as an editorial availability correction; this specialist does not own the shared file. No new executable instructions, example, fitted values or material ranges are supplied here.

When source closure is achieved, profile authoring provenance should include this packet, exact selected model/dossier and actual interface control implementation. The complete guide must explain phi_c (critical friction angle), hs/n (pressure stiffness/compression), ed0/ec0/ei0 (limiting densities), alpha (density dependence of peak strength), beta (density dependence of stiffness), plus thickness and the chosen loading controls. Values should come from packaged definitions rather than being duplicated editorial defaults. Starting-state prose must distinguish sigma_n from independent sigma_p, effective local shear tractions, density and specimen preparation; Jaky is a possible estimate, not an automatic reset.

At least two characteristic behaviours can be explained after closure: normal confinement affects tangential resistance, and permitted normal motion versus confinement changes dilation/normal stress response. A useful supported experiment would compare CV, CNL and CNS only if those named controls and complete initial context actually exist in the interface route. No such interactive instructions should appear while the entry remains reading-only.
