    - heading "Hypoplastic granular interface · fully rough HvWE" [level=2]
  - paragraph: Pressure and density govern coupled normal stress and shear traction beside a fully rough structure.
  - paragraph: This interface law describes a thin granular shear zone using normal stress, lateral stress, two shear tractions and void ratio. Its nonlinear stress rate couples shearing with changes in confinement and density. The fully rough realization inherits the original von Wolffersdorff sand law.
  - heading "What it describes" [level=3]
  - term: Confinement and sliding
  - definition: Normal confinement influences the shear traction developed during sliding.
  - term: Normal coupling
  - definition: Dense granular material can dilate during shear; restricting normal movement changes the normal stress response.
  - heading "Explore restrained dilation and changing shear direction" [level=3]
  - paragraph: Run the supplied combined shear-and-compression example, then set the normal strain change to zero. Inspect shear traction and normal stress together, and change the direction using the second shear angle. Keep the complete starting state when comparing runs; changing the starting density changes the material response.
  - heading "Material parameters" [level=3]
  - paragraph: Use a material-specific calibration of the eight inherited sand constants. Stress inputs and hₛ use pascals, and the friction angle uses radians. The supplied constants come from an original host-soil example; they are not an interface calibration.

  - heading "Starting state" [level=3]
  - paragraph: Supply all four local stresses and the void ratio, together with the starting path coordinate and all three controls. The example begins in compression with zero shear traction. Lateral stress is an independent state and evolves during loading; it is not reset at reversal. Example material constants and density illustrate the equations rather than a prepared interface specimen.
  - heading "Scope and limitations" [level=3]
  - paragraph: The laboratory prescribes normal compression strain and two shear angles along a dimensionless path. Effective Cauchy stress uses compression-positive signs in a fixed local frame with zero spin. Both shear directions and the evolving lateral stress are retained.
  - paragraph: The realization reconciles the 2016 interface equations with their original 1996 host; the technical dossier identifies the source corrections. It supplies no contact opening, roughness degradation, finite rotation or stress-controlled apparatus. Shear angles are prescribed directly; displacement divided by layer thickness is not substituted for the angle. No experimental calibration is supplied.
