# Prospective interface implementation contract

Task IMPL-interface2016-reconciled-v1, owned only new candidate models/research/interface2016/hvwe2016-reconciled-fixed-local.json and this directory. Material candidate creation is gated on the separate source-review-v1 final acceptance. The coordinator owns builds, shared integration and independent scientific approval.

The selected law is the fully rough HvWE interface, inherited original VW96 host, source-reconciled, fixed local zero-spin restriction defined by source-v2/RECONCILIATION.md. It is not literal substitution of the inconsistent journal host print. The exact2016 visual receipt gap stays disclosed. All eight host parameters and every reduced source stress/density mechanism are retained.

The increasing coordinate is dimensionless path, not physical time. Three prescribed dimensionless controls are normal_strain (compression positive), gamma_x and gamma_z (source shear angles). Stage derivative bindings are normal_rate, gamma_x_rate, gamma_z_rate. Value bindings normal_value, gamma_x_value, gamma_z_value are present to require complete context even though this rate law uses only derivatives. D has Cartesian entries D11=normal_rate,D12=gamma_x_rate/2,D13=gamma_z_rate/2 and remaining entries zero. Shear angle controls follow the simultaneous compression-positive sign conversion. No displacement/thickness adapter, finite-slip mapping, CNL/CNS solver or finite-spin transport is supplied.

Five persistent scalar states are sigma_normal,sigma_plane,tau_x,tau_z,e, first four in Pa. Component states use fixed_components; void ratio is scalar invariant. Stress output is effective Cauchy Mandel [sigma_normal,sigma_plane,sigma_plane,sqrt(2)*tau_x,0,sqrt(2)*tau_z]. Restricted Cartesian small_strain_3d is an explicit embedding of the local source subspace, not arbitrary 3D material capability. Positive normal strain reduces e; the nonlinear norm term has the negative sign in compression-positive equations. In-plane stress evolves independently and is never reset at reversal.

The illustrative material uses original1996 TableI Hochstetten phi_c=33deg,hs=1000MPa,n=.25,ed0=.55,ec0=.95,ei0=1.05,alpha=.25,beta=1.5. These are an inherited host example, not an interface calibration or reproduced experiment. Illustrative state [100000,80000,0,0,.67] Pa/dimensionless is a declared numerical specimen, not source preparation. Numerical p_ref=100000Pa scales error only. Practical bounded parameter ranges, positive-definite compression stress, positive e between ed and ei and finite real positive factors are admission restrictions for the numerical study, not a claim to the complete physical domain. No clamps or epsilon substitutions: exact z2=0 gives F=1; nonzero z2 uses its actual cubic invariants.

Initialization requires all states, parameters, coordinate and three controls. Every restart preserves all four context parts. Controls interpolate linearly over each advance; derivatives are per path coordinate. Holds retain the stress/density exactly when valid. Reversal changes prescribed derivatives without state reset. Any invalid parameter/domain/control, unrepresentable endpoint or exhausted trial/refinement budget rejects the complete advance and leaves parent state, coordinate, controls and parameters unchanged. Numerical integration uses the existing generic midpoint step-doubling integrator; it is not a source discretization or FE tangent.

Prospective policy.json freezes independent matrix-form reference cases, comparisons and acceptance before candidate observations. Independent reference uses ordinary Cartesian matrices, cubic matrix products and classical RK4 with fixed step refinement; it imports neither Atlas nor candidate expressions. Python interpreter comparisons follow only after reference convergence is accepted. Native/Wasm qualification remains a separate coordinator task.
