# Pairwise direction correction, candidate v2

The original candidate-v03.json (hash7e528930d05ec38ec1c286fa114749b4fc148affb454425297aac2c85f1f4977) is preserved as a rejected implementation. Independent exact-wire checks found two wrong finite stress responses from cancellation in normalized tensor mean subtraction; see independent-review/candidate-review-results-7e528930d05e.json. The original naive rotation-producer failure is separately retained in failed-rotation-v1/.

Candidate-v03-v2.json implements the same accepted CONTRACT.md equations and unchanged prospective numerical budgets. It extracts diagonal differences (a-b,b-c,c-a) and Mandel shears before normalization. Their maximum absolute value classifies exactly zero deviatoric input. Normalized deviator diagonals are (ab-ca,bc-ab,ca-bc)/3; off-diagonals are normalized stored shears. A norm on this bounded tensor supplies direction, avoiding subtracting a rounded hydrostatic mean, unscaled norm underflow and division by an underflowed r. The same method is used for old-state projection and current yield checks. No amplitude threshold, shear compliance, new DSL operator, source branch or runtime change is introduced.

Scalar component divisions are used deliberately: current Sym/scalar division first forms a reciprocal, which can overflow for subnormal divisors even when each normalized component is representable. The branch flag remains separate from the rounded scalar distortion magnitude. Exact full-zero strain returns the old full stress, and v_n/(1+0)=v_n. Minimum-subnormal inputs and the two failed near-hydro controls require independent exact-wire replay before any compiled qualification. Deep range overflow and nonrepresentable outputs may reject atomically; no all-binary64 accurate tangent is claimed.
