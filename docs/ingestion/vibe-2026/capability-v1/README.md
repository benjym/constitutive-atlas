## Algebra already available

`give_BE_LNH` 1067 defines a rank-one fourth-order inverse. With
`q = bBfact + cBfact + 3*cBfact*dBfact`, its action is

```
B_inv:X = X - q/(1+3*q) * trace(X) * I
```

This uses existing scalar division, `trace`, tensor scaling and addition. The independent `Fraction` check applies the inverse followed by `B:X = X + q*trace(X)*I` to ten tensors, checking all60 components exactly. The singular denominator `1+3*q` needs a source-supported admissible domain or branch; it must not be regularized without evidence. Absence of a generic matrix-inverse primitive is therefore not a blocker for **this** operator.

The macrostructure operators inspected at1128–1244 similarly use isotropic tensor action and dyadic contractions: `L:X = fs*(X + nu/(1-2*nu)*trace(X)*I)` and the added `T tensor I` acts as `T*trace(X)/lambda_act`. These reduce to the existing DSL. I1, I2 and I3 can be expressed with `trace`, `dot` and `determinant`; source `trace(Tstar^3)` has `cube_trace`, and symmetric square has `tensor_square`. Logs, exponentials, noninteger scalar powers and min/max are supported subject to dimensions and finite domain. This inspection is not a proof that every remaining article expression has been transcribed or that all AD branches are qualified.

## Layer-by-layer boundary

- **Python:** full model validation, scalar/sym expression interpreter and dimensional checks exist. `atlas.path` has named scalar controls and first derivative bindings, committed context and exact unchanged-start checks, but its derivative is per **dimensionless path coordinate**. It cannot honestly declare the VIBE physical clock. `atlas.schedule` serializes six mechanical component histories only. Explicit-state initialization is supported; reviewed preparation is a separate task.
- **Generated native and Wasm:** common compiler emits `time` and `strain_rate` locals from a fixed evaluator signature. The time integrator handles true seconds, rollback and prescribed rate stages; mixed schedules solve stress/strain components with rollback. `path_compiler` and `path_runtime.hpp` provide an additional named-control transport in a separate catalogue, but dimensionless semantics remain. Extending only Python would leave compiled backends unsupported.
- **History/restart:** current time schedule restarts require full state, strain, endpoint rate, parameters and time; controlled-path contexts require state, coordinate, controls and parameters. VIBE additionally needs exact external T/suction values plus any true scanning/reversal memory. No current THM schedule serializer/replay contract was found. Existing legacy history bridges must retain their own model/profile acceptance boundaries.
- **Browser/package:** current main atlas has actual timed, controlled-path and other dedicated profiles, and a literature-only VIBE reader profile in `web/model-profile-data.mjs`. Historical prose in `TIME_ODE_API.md` and `TIMED_SCHEDULES.md` saying the public site has five models/no timed UI is stale; it is not evidence of current browser absence. Current code has no VIBE THM-control laboratory or corresponding checked transport. Full E6–E8 must add/verify all required controls, complete state, physical holds, restart/replay, invalid recovery, readable profile and exact packaged/live hashes after numerical/agent admission.
