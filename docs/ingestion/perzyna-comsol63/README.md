# COMSOL 6.3 Perzyna elastoviscoplastic solid

Full-delivery task MODEL-perzyna-comsol63 is active. See [delivery ledger](DELIVERY.md), [source and contract](source-v1/README.md), [independent source review](source-contract-review-v1/REVIEW.md) and [numerical plan](execution-v1/PLAN.md).

The selected printed formulation uses isotropic elasticity, associative von Mises flow, constant yield stress and yield-normalized nonlinear overstress. This is a small-strain fixed-spatial zero-spin dry-total-stress model. The theory/settings discrepancy SC-PERZ-01 is disclosed in the source packet.
