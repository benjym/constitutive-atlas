# Perzyna numerical qualification v2 — prospective

No Perzyna native, Wasm or browser material execution has occurred. This plan reuses the unchanged generic physical-time-v2 schedule engine already qualified for Bingham; it introduces no constitutive runtime code. The exact new schema-v0.3 candidate is source-reviewed (7bfc3357); the theory/settings discrepancy remains explicit. Scope is small-strain, fixed-spatial, zero-spin, dry total Cauchy stress, positive K/G/yield/A and project exponent n∈[1,8]. This is numerical qualification of illustrative protocols, not calibration, vendor conformance or experimental validation.

`cases.json` fixes 107 ordered cases and requests: 72 radial holds (six Mandel bases, q/yield=0/1/2, n=1/1.5/2/3), eight signed constant-stress creeps, three public modes, hydrostatic rate, three noncoaxial reversal/hold histories, two custom parameter sets, two nonzero-memory histories, two passive rotations, coarse/fine refinement, actual-parent full-state restart, eight early invalids, late budget rollback, and recovery. Each backend executes every request twice. Wasm uses one persistent instance, including invalids and recovery; native uses a new process per call. Time is seconds. Six controls per segment are entirely strain-hold, strain-rate or stress-hold; no general mixed-control qualification is claimed.

References were generated before compiled observations. Holds and creep use independent closed forms; loading uses independent stress-plus-alpha RK4 with elastic compliance reconstruction, rather than the production thirteen-state backward Euler. Low8192/high16384 reference comparisons must pass state5e-11 and stress0.005Pa. `reference-convergence.json` retains all26 comparisons. The source oracle was independently verified, including 50-digit Decimal recomputation of 180 hold endpoints. Rotation checks are passive covariance, not finite-rotation capability.

All fine output state components must satisfy error≤max(3e-7,2e-5|reference|), stress error≤max(3Pa,2e-5|reference|). Coarse-only diagnostic floors are0.001 and1000Pa. Fine maximum state AND stress error must each be strictly less than coarse error/5. Default rtol1e-9/atol1e-12, max step5/12288s, min step1e-12s, budget1,000,000 accepted halfsteps, nonlinear tolerance1e-10,40iterations/depth40 are frozen, including public defaults. Coarse changes only rtol1e-4/atol1e-7. No post-observation tolerance, reference or gate relaxation is permitted.

The strict assessor checks exact requests/model/catalogue/solver/context, complete result schema, all point topology/time/segment sides, finite13state/6stress, trace-free plastic memory, nondecreasing alpha, exact entry-state continuity and prescribed rates. Early failures have exact messages and no committed points. The late test has a1e-6s committed prefix, budget2, exact later failure and only that committed sample/entry retained. Restart uses the observed parent's full state, strain, rate and clock, with independent analytical continuation from the parent. Exact repeat bytes and native/Wasm physical parity2e-10 are required; only explicitly listed iterative diagnostics are excluded from parity. Direct midpoint integrate-time API is excluded.

`synthetic_checks.py` manufactures a positive result fixture and26 corruptions to test the assessor only; it cannot establish material performance.
