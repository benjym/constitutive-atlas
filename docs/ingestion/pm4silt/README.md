## Equations and schema crosswalk

Notation for this packet: `pos(x)=max(x,0)` is the source Macaulay bracket; `dot` is the full in-plane Cartesian double contraction, including twice tensor shear. `a` in isolated printed formulas is treated as the printed symbol, not automatically corrected to alpha. Units: stress/moduli/strength/pressures Pa; strain, e, xi, lambda, ratios, fabric and all multiplicative coefficients dimensionless. phi values require explicit degrees-to-radians conversion. Bracket, cap and singular branches must remain explicit. Equations here are source crosswalks, not a loadable DSL model.

### Dimensional, sign and loading conventions

BodyEqs1–4 pp11–12 use symmetric2x2 effective sigma, `p=(xx+yy)/2`, `s=sigma-pI2`, `r=s/p`, with trace(s)=trace(r)=0. Store a tensor-shear representation `[xx,yy,xy]` or declared Mandel2 `[xx,yy,sqrt(2)*xy]`; never reuse `dev(Sym3)` or `trace/3`. A trace-free in-plane tensor may later reduce to two components, but no such alias elimination is presumed for source memory. q is the major-minus-minor in-plane principal stress difference, so `q=sqrt(2)*norm(s)` and M=2sin(phi_cv); no Lode dependence.

BodyEq5 has epsilon_v=epsilon_xx+epsilon_yy, while Eq6 subtracts epsilon_v/3 from the displayed2x2 strain tensor. Its in-plane trace is epsilon_v/3, not zero. This is consistent with restricting a3D plane-strain deviator (zz=-epsilon_v/3), but that is an interpretation, not a stated complete adapter. The stress decomposition /2 and strain decomposition /3 must not be made identical silently. R=n+(D/3)I and K/G use3D-looking factors despite the in-plane stress law. Exact meaning of omitted zz stress/strain/work and returned FLAC components must be sourced before a homogeneous point kernel.

Constitutive body assumes positive compressive p in logs/powers; Table3.2 explicitly uses FLAC tension-positive sigma and negative p0. A dedicated host-sign conversion must distinguish those contexts. Simultaneous sign flips preserve stress/strain work but do not fix a logarithm of negative p or a pressure-fabric product. No direct copy of signed Table3.2 into the positive-p body is admitted.

## Temporal integration and transactions

The manual uses incremental rate-independent effective stress plasticity. Physical FLAC time selects strain increment size/global dynamics, but is not an intrinsic viscosity/creep variable. Explicit integration without constitutive substepping is described at pp52–53; step-size sensitivity remains required. A physical-time hold with zero strain does not establish creep. FirstCall, Fsu and PostShake are explicit user/preparation events; they can change state/coefficients even at zero strain and must not be inferred from elapsed time.

**Table3.1 phase order:** (A) per-subzone initialize if assigned/FirstCall0; read strain; elastic predictor with committed G,K; trial distance/n/daxn; strict elastic test dist<m/sqrt2, otherwise loadingL with retained D,Kp; penalties for yield/bounding; image/backstress/stress commits to host candidate. (B) after fourth subzone area-average dvol,dstrain,p,sigma,alpha,n; apply consistency/bounding penalties again; calculate zone images/inner products; determine reversal; compute D,Kp for the past averaged step; compute plastic volumetric strain; conditionalfabric update; recompute xi/surfaces/G/K for next step; update initial/previous anchors/strain accumulators; update reversal anchors; publish zone stress,p,alpha,r. pp52 explicitly says all four subzones share D,Kp lagged from the preceding zone step.

This is a partial order: exact operands of reversal/fabric computations and overlaps of steps16/17 remain unspecified; averaged n need not be unit, so normalization choice must be sourced. Source “commit” inside a subzone is not permission to expose a partially updated zone to outer mixed-control trials. Atlas must stage all subzones/zone memory from one immutable caller parent and atomically publish only after host reduction and checks. Failure must restore preparation, old lag values, anchors, accumulators, host workspace and control flags as well as stresses. Repeated candidates must not accumulate history. These rollback requirements are engineering proposals, not claims that the unavailable DLL supplies such an API.

**Table3.2 startup:** obtain host stresses; tension check sigma11>0 replaces with negativepA/20 isotropy; compressive branch uses signedp0=min(-.5kPa,trace(sigma)/2); selectpmin; positionGamma from strength/currente; project stress if outsideMb; initialize alpha=r or reducedr; initialize true/previous/extrema anchors; setG=G0*pA*sqrt(-p0/pA),K fromnu,Kp=100G,D=0; initializepzp=p0/100,zpeak=zmax/100000,zxp=0,zxpPk=-zmax*p0/50,z=zin=zd=zcum=0. Equality sigma11=0 and Mfin=Mb branches are not stated. Startup strength-ratio input must be re-evaluated on explicit FirstCall reset, not ordinary continuation. Full sign conversion remains open.

No source algorithmic tangent is provided. Any initial implementation must distinguish derivative of a selected smooth branch from derivative of penalty/reset/host averaging events; AD alone does not settle nonsmooth or source branches. Root acceptance policies must include caller-step refinement, four-subzone versus homogeneous scope, rollback after positive work, equality/zero-direction domains and same-parent recovery.
