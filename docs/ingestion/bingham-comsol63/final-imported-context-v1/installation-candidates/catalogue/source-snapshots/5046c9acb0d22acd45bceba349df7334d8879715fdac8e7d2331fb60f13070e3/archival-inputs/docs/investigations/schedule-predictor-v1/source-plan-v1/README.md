## Proposed exact change

`proposed-schedule.patch` targets the exact old `cpp/include/atlas/schedule.hpp` hash in `source-bindings.json`. It adds one optional generic helper before `controlled_backward_euler` and invokes it once after the original unknown vector is constructed. There is no model-ID branch, clipping, projection, altered domain, new solver setting, changed residual, modified Newton derivative, line search or acceptance rule.

The helper starts with the existing unknown vector as an immutable fallback. It requires finite t0,t1,h with h>0, forms a strain-rate guess from the **current** path rates on prescribed-strain components and **previous solved strain rates** on stress-controlled components, then enforces existing axisymmetric radial equality. `path.rates` on stress controls is a stress rate; using it as a strain rate would be dimensionally wrong. The stress-control increment unknowns remain the existing previous.rate×h values.

Evaluate the generic RHS at the incoming state and t0 with that combined rate. Require a finite correctly sized RHS. Set only the material-state part of a local candidate to previous.state+h·RHS; retain its original stress-controlled increment guesses. Require every unknown finite, then evaluate the complete existing `controlled_residual` at t1 and require a finite result. This validates the candidate under the actual endpoint rate context, endpoint-time model domain, state equations and observables. It deliberately does not require the predictor to solve the equations or mixed controls. There is no standalone `time_domain` call with an artificial zero rate: the complete endpoint residual already invokes normal generated model/domain evaluation at the actual candidate rate.

Only after all checks does the helper replace the local initial guess. Otherwise it returns false and leaves every original unknown byte/value unchanged; the original Newton solve proceeds. The predictor itself never becomes an accepted state, advances the clock, increments accepted-substep counters or mutates the committed parent. Newton still must satisfy the original residual and domain at the actual endpoint. A successful RHS evaluation at t0 alone is insufficient.

This is an initial-guess strategy, not a theorem of convergence. An admissible FE guess may be farther from a nonlinear root, overflow, encounter a discontinuous domain, or still lead to failed Newton. Endpoint admissibility in doubles does not certify its AD Jacobian. If an admissible predictor later fails Newton, this minimal patch does not add a second whole solve from the old guess. Tiny positive accumulated state can also cancel toward zero with roundoff. Native/Wasm evidence and regressions must decide whether this bounded change is suitable; no universal cure is claimed.

## Independent fixture and test artifacts

All three new JSON drafts are complete explicit v0.3 physical-time ODE formulations, with explicit state, dry total-stress observable and units. They are synthetic verification equations, not material catalogue/admission proposals. Schema/expression/unit checks passed without evaluating trajectories; `schema-checks.json` records them.

- `fixtures/test-predictor-boundary.json`: x′=trace(D), α′=max(x,0)/τ, domain α≥0, stress=KxI. At x0=.125,α0=0,τ=1,h=.25,trace(D)=−1, the exact **BE discrete root** is x1=−.125,α1=0. The old initial Jacobian's full Newton α direction is h x0+h²D=−.03125, so every positive backtracking fraction is outside the domain. The FE initial guess is xguess=−.125,αguess=.03125, admissible; the inactive endpoint branch admits a Newton correction to zero. Boundary tests include x0=0, the smallest positive double,2^-50 and.125, stale incoming prescribed strain rate, and outward loading.
- `fixtures/test-predictor-fallback.json`: x′=−x/τ, domain x≥0, stress=KxI. At x0=1,τ=1,h=2, FE predicts−1 and must be discarded without changing the original unknowns. The exact BE root is1/3 and remains admissible. This tests fallback as a functional requirement, not merely a branch counter.
- `fixtures/test-predictor-clock.json`: x′=time/τ², domain time<time_limit, stress=KxI. At t0=3,h=.125,τ=2,x0=0, the FE guess is.09375 and the BE endpoint root is.09765625. Changing time_limit to3.1 must invalidate the endpoint and retain the original guess; using the incoming time for endpoint validation would incorrectly accept it. Zero-duration predictor attempts must also preserve the fallback.

`test_schedule_predictor.cpp` is a proposed native test source, not installed or executed by this worker. It directly checks helper selection and exact preservation on fallback, direct controlled-BE roots for all three fixtures, mixed Kelvin controls using current prescribed rates/prior solved stress rates with untouched stress-increment guesses, and Maxwell axisymmetric rate/state symmetry with one radial unknown. It uses the existing tensor API `identity<double>()`. The fixture parameter order is tau,Kmod[,time_limit] as declared. The parent must install exact files into its isolated capability tree and let the existing fixture compiler verify that generated order/API before execution.

**Discrete root versus continuous accuracy:** the boundary example's continuous accumulated α at t=.25 is .125²/2=.0078125, not zero. A full BE step and two halfsteps can both return zero and alias its initial active interval. The direct test proves only admissible Newton access to the correct BE endpoint root. It must never be reported as continuous-path accuracy or as fixing the separate estimator blindspot. The unchanged source-motivated Bingham cap and complete original physical gates remain decisive.
