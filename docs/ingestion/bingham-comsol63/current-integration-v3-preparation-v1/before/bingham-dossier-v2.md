Exact definition: `bingham-comsol63-mises-perfect-zero-spin-ode` (schema0.3). This is the COMSOL6.3 Bingham continuous law with isotropic linear elasticity, constant positive yield stress, associated von Mises flow, no kinematic hardening and thermal function None. It uses infinitesimal strain in a fixed spatial frame with zero spin, Mandel components and compression-positive dry total Cauchy stress.

Holds above yield relax the deviator toward Y while the hydrostatic stress remains constant. Stress holds above yield produce creep; reverse loading crosses an elastic interval before reverse flow. Alpha never resets on reversal.
