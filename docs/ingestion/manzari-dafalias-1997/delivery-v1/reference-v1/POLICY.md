# Prospective source reference and comparison policy v1

Frozen before the first reference execution or compiled observation, 2026-11-02. Scope is original 1997 constant-m Table 1 law with extension coefficients from p266, first source b_ref alternative on p262. No production model import or compiled oracle.

Cases: isotropic p0=160 kPa, q0=alpha0=0; e0=0.65 (dense) or 0.85 (loose); axial compression +0.02 or extension -0.02; each under undrained (trace strain zero) and drained constant radial effective stress 160 kPa. Checkpoints at absolute axial strain 0, exact elastic first yield, .0005, .001, .002, .005, .01, .02. Pat=100 kPa is a declared project choice, distinct from source pref=160 kPa. All stress calculations here use kPa; serialized comparison states use Pa. Full strain (axial and equal radial), p, signed q, all stress components, scalar alpha and its full diagonal tensor, and void ratio are retained.

Reference is scalar source consistency-eliminated RK4 with maximum axial step 2e-6 and 1e-6. First yield is analytically split; post-yield branch sign fixed for monotonic paths. A refinement pair must agree at every checkpoint: stress 0.005 kPa+2e-5*max(1 kPa,abs(value)); alpha 2e-6; e and radial strain 2e-7. Yield drift absolute 2e-5 in eta-alpha-z*m. Finite positive pressure, positive hardening-distance denominator, and positive plastic multiplier required; unexpected failures are retained and block that case. No tolerance changes after failure. Analytic hydrostatic elasticity is checked independently, with the exact pressure power integral; unloading reversal is tested only inside the elastic wedge, not claimed as full cyclic plastic qualification.

Prospective native/Wasm versus refined source reference: every named checkpoint, including full stress, alpha, e and radial strain when backend supports stress control. Stress error <=100 Pa+0.01*max(1000 Pa,abs(reference component)); alpha component <=0.002; void ratio <=2e-4; radial strain <=2e-4. These deliberately bounded numerical qualification tolerances are distinct from the tighter reference convergence gates. Strain-replay comparisons use the source radial/axial checkpoint path, with linear interpolation between reference microsteps rather than assuming a single straight chord reproduces a curved stress-controlled path. No missing/failing case is counted as a pass. Both backend outputs must match the same reference; mutual agreement alone is insufficient.

Hydrostatic elastic pressure cases trace strain +/-0.001 from 160 kPa (e0=.65) use p^(1-a)=p0^(1-a)+(1-a)*K0/pat^a*epsilon_v; e=e0-(1+e0)*epsilon_v. A tiny undrained elastic cycle to 25 percent of first yield and back must return p,q,alpha,e exactly to analytic roundoff expectations.
