    - heading "Ramberg–Osgood · reversible nonlinear elasticity" [level=2]
  - paragraph: A reversible nonlinear stress–strain law with a smoothly changing stiffness.
  - paragraph: This three-dimensional Ramberg–Osgood deformation law relates the current stress to the current strain. Unloading retraces loading, so nonlinearity alone does not imply permanent plastic deformation.
  - heading "What it describes" [level=3]
  - term: Nonlinear stiffness
  - definition: The response departs smoothly from the initial elastic slope.
  - term: Reversible unloading
  - definition: There is no plastic-strain memory or hysteresis in this formulation.
  - heading "Explore the response" [level=3]
  - paragraph: Use a small monotonic strain path, then reverse it to explore reversible nonlinearity.
