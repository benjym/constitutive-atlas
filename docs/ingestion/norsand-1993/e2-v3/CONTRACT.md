## Generic profile

Extend v0.3 with `time_dependence: strain_path`, `equation_form: path_ode`. The independent coordinate is a dimensionless monotonically increasing strain-path coordinate, explicitly named/labelled by the model. It is not seconds or a fictitious strain tensor. State is arbitrary persistent scalar/symmetric fields, <=32 components, with the existing explicit initialization and state semantics. Stress binds the symmetric Pa observable `stress`, effective/total/none. `axisymmetric_x` restricts the stress output to equal radial components/zero shears; no unused strain input is supplied. General finite deformation/spin is excluded.

Required coordinate input `path_coordinate` is scalar dimensionless/stage/finite. Other equation inputs are declared scalar controls with units, stage sampling and an explicit binding to a control name and derivative order0(value) or1(derivative per dimensionless coordinate). Every input is supplied even if absent from expressions. All declarations sharing a control agree in units. Names cannot collide with state/parameters/derived/coordinate/reserved names. Controls are a closed named mapping of start/end values per advance, linearly interpolated at stages; derivatives are constant slopes. No arbitrary callback or undocumented default. Discontinuities require new advances with explicit matching physical state/context; the caller owns complete control history.

Advance requires finite `start_coordinate`, nonnegative finite `progress` and a finite representably later endpoint when progress>0. Zero progress requires constant controls and is exact state/coordinate identity after full initialization/domain validation. Negative progress rejects; no backward/cyclic constitutive rule is implied. Positive progress with identical endpoints after rounding rejects. Errors never mutate parent state, controls, parameters or output buffers; failed whole advances return the original complete parent state and coordinate, even after accepted internal substeps. Restart requires full state, coordinate, complete parameters and current controls. A committed context retains its current control values; the next advance must match those start values exactly. Replacing control context cannot silently reconstruct a stress jump; explicit reinitialization is a distinct caller operation, never an advance. Invalid parameters/settings/input names/shapes/nonfinite values reject before evaluation.

Generic engine: declarative DSL typed equations per path coordinate; common expression checks and C++ generation, no model-ID branch. Integrate with adaptive explicit midpoint, full step versus two half steps, fixed Richardson factor3 and declared state scales. Accept two-half-step state without extrapolation. Initial/full/midpoint/accepted states must pass full finite/domain checks at the corresponding coordinate and controls. Freeze absolute/relative tolerances, min/max step, depth/substep budgets; all are execution settings, not material constants. No physical-time rate or numerical tangent promise. Retain evaluator metadata/control ordering and exact model/catalogue hashes.

## Exact original NorSand active axial reduction

Use dimensionless shear progress `s`, with `eq(s)=eq0+(s-s0)`; the caller may retain a fixed nonzero coordinate offset and must preserve `eq-coordinate` on restart. controls `C` (Pa), `K` (dimensionless), `C_s` and `K_s` are their stage derivatives, where the controlled stress combination is `C=p-K*q`. `K=1/3` gives cell pressure, `K=0` gives mean pressure; interpolation of other combinations is mathematical mixed control, not additional material physics. State is `eta,e,ev,eq`; `eq'=1`, `ev'=D`, `e'=-(1+e)*D`. The e rule explicitly selects current-volume incremental strain/incompressible grains; accumulated volume strain is logarithmic-volume strain, not finite nominal engineering strain. `eps1=eq+ev/3`, `eps3=ev/3-eq/2` are accumulated source work-conjugate increments, not exact finite principal stretch strains. Figures are qualitative source context, not digitized numerical acceptance.

Define `B=1-K*eta`, `p=C/B`, `q=p*eta`. Obtain `r=pi/p` from Eq10 (exact N=0 branch), `pi=p*r`, `psi_i=e-Gamma+lambda*ln(pi/pref)`, `rL` from Eq11 using this current psi_i, `D=(M-eta)/(1-N)`, `Y=(p/pi)^(N/(1-N))` or1 at N=0. Differentiate yield and mixed control, then substitute Eq12:

```text
eta' = M*Y*B/(B+K*M*Y) * [h*(rL/r-1) - C_s/C - K_s*eta/B]
```

This retains every original active yield/flow/hardening branch. `pi` is reconstructed algebraically from the active constraint; it remains a physical history observable whose reconstruction requires the retained control context. It must be compared against an independent reference integrating `pi` directly. `eta,e` plus current controls determine `pi`; on-yield initialization provides no independent pi degree of freedom. `ev,eq` retain strain history for replay/plots. Stress is the fixed axial Mandel embedding of p,q. No arbitrary radial strain is ignored.

Domains: proposed qualified numerical region M>0,h>0,lambda>0,0<=N<=.39; pressure>0,e>0,eta>=0, positive power bases, B>0 and B+K*M*Y>0. Exclude unloaded/interior states, negative progress, arbitrary rotation/Lode continuation and later elasticity/cyclic rules. Additional bounds are prospective qualification limits, not universal source limits. Reject changing controls if they leave this region. Complete physical/caller state must remain reproducible; no clipping/floors/projection.

The source explicitly studies conventional monotonic drained triaxial compression and discusses constant p. This profile exposes those active original controls. It does not claim a new unloading law; no branch is discarded to make a generic full-strain driver pass.
