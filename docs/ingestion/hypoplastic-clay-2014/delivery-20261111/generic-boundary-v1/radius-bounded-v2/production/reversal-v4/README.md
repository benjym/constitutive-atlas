# Mašín 2014 fixed-plane clay with intergranular strain: qualified example

The approved laboratory example replays 33 observations from the exact mixed six-component loading and reversal path. It uses a synthetic normal-compression start with zero memory and reports all six effective Cauchy stress components, void ratio and six directional memory components. See the [scope and limits](CONTRACT.md). The broader controlled paths below are backend qualification; they are not additional public presets.

The original near-zero failures reached the material subdivision cap because the memory defect exceeded its existing limit. The [independently reviewed update](REVIEW.md) retains the affine part of the source law up to its exact branch boundary, then integrates the nonlinear correction in a transformed coordinate. It retains the original outer gates and compares two fixed quadratures inside the reversal step. All stages count against the existing probe budget.

The final frozen matrix passes 12 prescribed-strain paths, four controlled positives, and both exact full-path refusals on native and Wasm. Both refused Wasm cases pass same-instance hold and recovery. The independent approval also checks the 4,260 unchanged native finite/history results. The [E4 receipt](e4.sha256), [backend parity](backend-parity.json), [preset](recorded.json) and [approval](approval.json) bind the exact scope.

The standard website build verifies the retained engine bytes, compiled catalogue, full replay, export and invalid-scope recovery. The package browser gate opens the example from its catalogue entry, compares the export to the qualified response, re-imports it and repeats the replay on a narrow viewport.

The public engine is the exact qualified Wasm pair; the ordinary controller and retained model engines are unchanged. To reconstruct the dedicated source inputs in a scratch tree: copy the ordinary C++ source, scalar CMake module and weighted profile into matching relative locations; apply [the original solver source delta](solver-source-delta.patch) only in scratch; run the dedicated `prepare-recorded-overlay.py <build-dir>`; generate the candidate catalogue with `atlas.compiler.generate` for the exact model only; then configure the profile with `ATLAS_RETAINED_RUNTIME` pointing to that source closure. The reconstructed transport, solver and linearization overlays, recorded header and generated files [match the tested bytes](release-source-reconstruction.log). This does not change the retained packages' inputs or claims.
