# Prospective implicit warm-start design assessment

The frozen v4 joint triaxial study has a hard timeout failure, not a qualified result. The retained check_native_triaxial.log identifies dense target0.005,N1600 with residual7.8125e-13/path3.90625e-10 and120second timeout. No tolerance, resource or timeout waiver is justified. Native domain704/94pass is a separate bounded result; it does not resolve joint triaxial qualification.

A separately frozen generic opt-in warm-start runtime study is defensible. Keep the full solve starting at its actual parent. For the first half, propose an arithmetic state mean of actual parent and full endpoint; for the second half, propose full endpoint with the actual converged half as committed parent. This changes a Newton initial guess only. Constitutive equations, parent histories, endpoint acceptance, error estimator, accepted two-half trajectory and all work/timeout limits must remain exact. No performance benefit is established before measurements.

Required selection contract:

1. Pass candidate seed separately from actual committed zn. Every residual/Jacobian evaluation retains that solve's actual zn and de. In particular, second-half history is the actual half state, never the full candidate or original macro parent. Do not alias seed/output/parent storage.
2. Check exact state length before indexing, finite entries, transient reset, ordinary solution admissibility and finite value residual. Compare reset parent and reset seed using the identical residual scaling/norm and multiplier predictor substitutions used by that implicit solve's first Newton iteration. Parent and seed evaluations must both be valid and finite; choose seed only for strict decrease. Equal/worse/invalid guesses retain the exact previous starting state.
3. Preserve predictor initialization and transient semantics. Arithmetic mixing of history carriers or multipliers is a guess, not a new physical history or commit. It must never alter source memory, source domain or exact zero-load identity.
4. Keep45iterations and the same backtrack bound, reserved-three-solves accounting, accepted-half budget, depth bound and120second timeout. Selection value evaluations should be disclosed/countable. Do not add a fresh cold solve after warm failure or extra Newton iterations. A finite value residual does not guarantee a usable Jet derivative at a nonsmooth seed; existing solve failure/recursive rejection remains valid.
5. Keep disabled legacy and cold full-solve paths exact. Prefer an explicit separately validated opt-in flag or separately identified runtime realization; do not silently change an already qualified legacy route.

The generic residual may have multiple roots. Smaller starting residual alone cannot prove convergence to the same root as the cold start, or even better convergence. Therefore this is performance-motivated but not universally behavior-preserving. The source scalar positive branch is unique in the hydro/proportional midpoint cases, but arbitrary plastic and generic nonlinear models require numerical evidence. Do not reuse old runtime qualification without checking changed source/paths.

Prospective tests should cover seed absent, wrong-size, nonfinite, inadmissible, equal, worse and genuinely improving; exact committed-parent immutability; transient reset and multiplier predictor handling; second-half own-parent reference; zero-hold signed-carrier identity; iteration failure without extra retries; strict disabled-path identity; rotation/tiny-pressure/source-event qualification; native/Wasm source and transaction parity. Freeze these and the unchanged domain, joint triaxial, fixed-diagnostic, lifecycle, legacy, supplemental source gates and timeouts before observing the new runtime. Retain all prior v4 partial raws and the timeout failure under their original identity.

This is design advice only: no exact implementation was supplied/reviewed, no compiled execution, no performance/qualification approval and no E5 admission. The smallest next step is an isolated staged implementation and prospective source/policy/test freeze for independent code review before the coordinator's serial build.
