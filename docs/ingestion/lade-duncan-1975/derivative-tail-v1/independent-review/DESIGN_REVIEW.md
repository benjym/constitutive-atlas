All derivative slots j>=n then begin bitwise identical (+0). For deterministic lane-independent primitives, equal input lane bits imply equal result lane bits, with identical primal calculations and active-column expressions. Compute all active lanes plus one representative lane n, then copy its exact bits to every other dormant slot. Induction preserves all38lane results, including signed zero, infinities and NaNs. This retains the dormant-lane0*infinity invalid behavior that simply dropping inactive arithmetic could erase.
