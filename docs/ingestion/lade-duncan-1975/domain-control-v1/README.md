# Lade–Duncan1975 pressure-domain repair study

This is an isolated numerical realization of the complete original1975 differential law. It is not a new source formulation, public model approval or atlas delivery. The [readable source crosswalk](../delivery-v1/supplied-original-v2/README.md), [source audit](../delivery-v1/supplied-original-v2/independent-review/) and retained [v2 failure checkpoint](../delivery-v1/supplied-original-v2/candidate-v2/README.md) remain the scientific provenance. Copyrighted originals remain private.

The [v3 definition](model.json), SHA256 `2665b192d3e25b163227037ef7c9f08d2a86e26563a2af8e70a29a91260a45fe`, retains original parameters, local Eq19 endpoint plasticity, fixed-kappa2 flow derivative, signed history-gap state, preparation and stress/strain conventions. It evaluates the elastic modulus at the committed parent pressure. Dividing the stress residual by the positive dimensionless parent least pressure preserves the equation zero set while controlling Newton error relative to pressure. These are declared first-order numerical choices; the source does not prescribe this algorithm.

The staged common-engine change adds opt-in implicit step doubling. It compares one full solve with two half solves and commits the two-half endpoint only when the declared error test passes. Its positive-stress mode uses Mandel Frobenius stress defect divided by the smallest positive least pressure among parent/full/half/two endpoints. Other state components use their existing declared scales. There is no pressure floor or model-specific runtime branch. Rate and physical-time profiles are not silently routed through this incremental controller. Six-setting behavior remains on the original branch when the path tolerance is zero.

The [prospective policy](POLICY.json) and [39-file freeze](prospective-freeze.json) precede all compiled material observations. A [separate review](independent-review/PROSPECTIVE_REVIEW.md) accepts only running the isolated study. Exact-arithmetic hydrostatic and fixed-positive-tensor proportional paths cannot be advanced beyond their finite positive-pressure lifetime by the left elastic rule. This is not a general3D event theorem. The finite-precision native/Wasm campaign is therefore required independently.

The [checker audit](independent-review/CHECKER_AUDIT.md) found coverage omissions without invalidating the source formulas. A separately identified [supplement](SUPPLEMENT_POLICY.json) adds full elastic invariants, tiny-pressure source accuracy, cumulative successful-prefix event checks, recovery after every domain failure, typed finite Wasm arrays, laboratory strain/control parity and a pressure-relative comparison. Earlier unexecuted supplement designs remain under supplement-design-v1/ and supplement-design-v2/. The original campaign and acceptance criteria are unchanged.

Current evidence:12interpreter checks and16synthetic generic metric checks pass; isolated native targets compile. Full native qualification is running. Wasm and supplemental execution await the appropriate preceding gate and independent prospective decision. No numerical qualification, E5 approval, shared runtime integration or browser/live delivery is inferred from the build.

## Reproduction

Build commands and toolchain/artifact digests are in [native-build-receipt.json](native-build-receipt.json); builds use one explicit target with `--parallel 1`. From the repository root, run the frozen native scripts separately: check_native_domain.py, check_native_triaxial.py, check_native_lifecycle.py and check_native_legacy.py. Supplemental check_domain_supplement.py must run only after its prospective review and original domain report exist. The Wasm checker replays literal saved native requests and check_wasm_source.py applies the same independent source gates to its saved responses. A timeout or missing aggregate report is a failed/incomplete campaign, never a pass. Raw responses remain in ignored .local/lade-domain-control-v1/ and are bound by report hashes.
