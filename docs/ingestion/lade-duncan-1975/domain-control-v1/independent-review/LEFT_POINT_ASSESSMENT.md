# New left-elastic candidate: independent assessment

The coordinator proposes a separately identified candidate v3: source E evaluated at committed previous stress, endpoint plastic Eq19/flow and coefficients otherwise retained; stress residual divided by previous dimensionless least principal pressure; generic opt-in relative step doubling accepting two actual half steps. This assessment addresses the proposal, not exact candidate bytes or acceptance results.

The hydrostatic one-sided lifetime argument is sound for arbitrary step lengths when exact positive forward-Euler elastic endpoints are used. Let u=p/pa, unloading length L>0, and 0<n<1. A positive FE step obeys

    u_new=u_old-Kur*L*u_old^n,
    L=(u_old-u_new)/(Kur*u_old^n)
      <= integral(u_new to u_old) du/(Kur*u^n).

The inequality follows since u^-n>=u_old^-n throughout the interval. Summing telescopes over any positive accepted substeps, including two-half acceptance: consumed strain is bounded by (u_initial^(1-n)-u_final^(1-n))/((1-n)*Kur), strictly below the continuous zero-pressure critical length. Consequently a wholly completed request beyond that exact hydrostatic event is impossible for exact positive endpoints. Finite nonlinear solve errors are a separate issue; the residual policy must make the assertion meaningful under actual tolerances and reject unresolved boundary requests.

The split is a source-consistent first-order numerical realization on smooth interior branches, not a source-mandated scheme. Relative to an endpoint elastic coefficient, E(Sprev)-E(Snext)=O(increment) and multiplying the elastic strain increment changes the local residual by O(increment^2), under bounded interior derivatives. Endpoint plastic work/flow may remain implicit. Branch transitions, repeated minima and vanishing pressure require separate numerical qualification; a smooth Taylor argument does not cover them. The new sampling must appear explicitly in model identity and policy, preserving all failed-v2 bytes and original reference/refinement bounds.

Preconditioning by sminprev=lambda_min(Sprev)/pa preserves the exact stress-residual zero set on the positive parent domain. Because sminprev is dimensionless, residual units remain Pa; existing Pa residual scaling then measures stress defect relative to previous least pressure. This addresses the specific absolute-residual stagnation mechanism. It is not a pressure floor, and does not authorize silent division overflow, underflow, state projection or tolerance adjustment. Safe repeated-min evaluation is still required at the previous hydrostatic state: constancy with respect to current Newton variables does not remove a primitive's primal multiplicity restriction. Freeze residual sufficiency and work/depth limits before observations.

There is no corresponding all-3D one-sided theorem from this scalar proof. Plastic coupling, changing eigenvectors and the evolution of the least principal derivative can alter the local pressure trajectory. Positive-definite numerical endpoints do define a positive-definite linear interpolant because the SPD cone is convex; that is a fact about the numerical path, not proof that the continuous source path avoids the boundary between samples. Relative least-pressure-scaled tensor error, residual adequacy, decreasing-step studies, rotated anisotropic unload paths and near-event cases are therefore necessary evidence. A general claim of exact event enforcement would still need stronger validated source-domain monitoring; bounded first-order numerical qualification need not be described as such a proof.

This proposal is a credible new realization that can remove the demonstrated hydrostatic delayed-extinction defect without a hydrostatic-only kernel. Its bounded general3D behavior, native/Wasm consistency, interior accuracy and resource-exhaustion rollback must be assessed against a frozen prospective study. No implementation or E5 approval is given here.
