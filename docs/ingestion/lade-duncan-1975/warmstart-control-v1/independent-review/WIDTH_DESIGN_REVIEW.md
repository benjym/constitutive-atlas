## Equivalence conditions

The present Jet has38fixed derivative slots, while implicit_step seeds only n state columns. For a state-only residual evaluation all committed-history/loading/parameter Jets are constants, and unknown state seeds are columns0throughn-1. Provided no live input derivative lies outside that interval, forward differentiation is lane independent. By structural induction each primitive's primal expression and each active derivative expression are unchanged; restricting loops to active n preserves these expressions. Dormant slots can remain exact zero if every newly constructed Jet zero-initializes all38slots and every copy/branch operation receives inputs satisfying this invariant.

This proof is conditional, not a blanket claim of identical branch/failure behavior. IEEE nonfinite arithmetic in unused lanes (for example zero times an infinite derivative coefficient), singular spectral branches, checked primitive contracts and full-Jet finiteness checks can affect success. The new code must retain the prior checked-domain/failure policy and test these cases explicitly. Do not silently change finite_value to inspect active lanes only. Keep fixed-size storage/ABI and zero initialization; this proposal removes derivative work, not storage initialization or scientific checks.

The width must be bounded to the valid state dimension and max_derivatives. A thread_local current width defaults to38. A noncopyable RAII guard captures the exact previous width and restores it on every return, thrown exception and nested scope; nested guards must restore their parent width, not blindly38. Evaluate all state-Jet expressions inside the guard, extract the complete n-by-n Jacobian there, and return no live Jet whose suppressed lanes are later expected to be differentiated. Scalar State outputs and diagnostics may escape. Do not change primal, residual-scaling, convergence, predictor, warm-start, line-search, domain, history or rollback algorithms.

Scope must be only the state-only implicit Jacobian path. Mixed laboratory/control AD may use n+6 columns, external tangent evaluations may seed arbitrary lanes, and rate/other generic operations retain default38unless independently proved. Do not infer width from a model's persistent field count if transient/multiplier unknowns are part of the solved state. If an implicit call is nested inside another differentiation context, outer derivative inputs cannot simply be truncated; either prove none are passed or reject use of the scoped optimization there.

Inventory every derivative access/loop, including max_derivatives, hard-coded bounds, range loops over d, d.size(), trace_accuracy, spectral/normalized invariants, determinant/cofactor/centered/principal-range helpers and scalar checked primitives. Distinguish arithmetic loops that can safely shorten from storage-size validation, input-finiteness checks and zeroing that must retain full-array semantics. A partial inventory may preserve correctness but miss most performance benefit; a global replacement can break unrelated generic contracts.
