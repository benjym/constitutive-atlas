# Maxwell continuous-law execution plan v1

Frozen before any compiled Maxwell result, 2026-11-01. Implementation owner: coordinating parent. Source-law admission is independent of execution. Exact candidate bytes are copied into a separate research catalogue; no equation, parameter bound or source convention is changed. The trace-projector interpretation is a documented draft choice; no independent scientific sign-off is implied.

Use the ordinary compiler, cpp/main.cpp and existing time.hpp/schedule.hpp. The cmake/maxwell project generates one Maxwell catalogue, with one explicit atlas_maxwell_solver target. Build native first, serial `--parallel 1`, assess retained responses, then Wasm serially using the same source freeze. Do not build or execute vendor programs. Do not change existing catalogues, model bytes, engine, schemas or historical evidence. Keep the original ingestion manifest intact.

Acceptance is fixed in reference-cases.json and tests/test_maxwell.py. Independent exponential solutions cover full-tensor constant rates at tau=0.2,2,20s over durations 0.01,0.5,4 tau, plus volumetric elasticity and relaxation. Timed mixed controls cover all-stress creep, sampling invariance, oedometer confinement, full-tensor load/hold/reverse and temporal refinement. These references are created without interpreter or compiled trajectory output. Scheduled oedometer starts from the analytical elastic equilibrium, not zero stress.

Direct stress error <=0.05Pa, scheduled stress <=15Pa (deliberately coarse refinement diagnostic <=1000Pa); scheduled strain <=2e-7; all output times/states including transitions checked. Fine scheduled relaxation must improve on the preselected coarse settings. Temporal estimates <=1 and nonlinear residuals <=1e-10. These are bounded software gates, not empirical accuracy claims or guarantees over the very broad model parameter declaration.

Two identical calls per case must replay exactly within one backend. Wasm repeats all calls in the same module, including recovery after invalid duration, viscosity, omitted/short state and forced budget exhaustion. Direct late budget failure must restore full incoming state/time after nonzero accepted internal work; schedule failure must preserve the last committed interval/entry. Collect raw responses before assessment and retain failures without widening limits. Cross-backend physical channels compare at 1e-6Pa stress and 1e-11 strain; times, identities, null positions and control metadata must agree. Adaptive work counts may differ; both diagnostic bounds must independently pass. No backend agreement substitutes for analytical checks.

Actual complete schedule restart and CLI example/replay are verified in a separate retained transaction receipt, using last state, strain, rate, parameters and clock. The comparison uses the same frozen stress/strain limits. Missing-state validation and legacy untimed rejection remain enforced.

Freeze all compiler/schema/header/source inputs, model, references, assessors and build definitions by SHA-256 before building. Copy exact build inputs to a private source closure for execution; verify against the freeze before native and Wasm. Preserve source hash mismatches as blockers. Numerical evidence applies only to the dry, total-stress, fixed-frame small-strain continuous law. Vendor central-difference equivalence, finite rotations, saturation, experimental calibration, browser timed UI and scientific admission remain outside this task. Delivery includes a dedicated build target and runnable example JSON files, with documented local commands.
