## Proposed complete material-point contract

Use the explicit v0.3 formulation and state declarations in [the v2 crosswalk](../supplied-original-v2/crosswalk.json): strain-path incremental residual, infinitesimal3D fixed-spatial/zero-spin, compression-positive Mandel tensors, effective Cauchy stress `sigma`, persistent scalar `h` recording the maximum accepted principal-stress difference. Select drained/effective calibration; no pore-pressure law or conversion. This retains the original constant-nu Eq15 closure, not later E-nu/E-B variants. The crosswalk remains historical; this supplement selects its previously open numerical choices.

For each internal increment, let `a_n,c_n` and `a,c` be ordered maximum/minimum principal stresses of committed/current stress. Define `D_n=a_n-c_n`, `D=a-c`, `abar=(a_n+a)/2`, `cbar=(c_n+c)/2`, `Dbar=abar-cbar`, `Fbar=2*(c_cohesion*cos(phi)+cbar*sin(phi))/(1-sin(phi))`, `Sbar=Dbar/Fbar`. This is an implicit arithmetic average of endpoint principal stresses, not the extrema of an averaged tensor. Original1642 specifies average principal stresses; original1646–47 uses extrapolated estimates in a particular finite-element algorithm. The implicit endpoint average is an Atlas discretization choice and must be labelled as such.

At an internal solve choose modulus in this order:

1. If `D<h_n`, unloading/reloading uses `E=Kur*pa*(cbar/pa)^n` (original Eq13; memory is max D, not max S).
2. Otherwise primary loading with `Sbar<1` uses `E=K*pa*(cbar/pa)^n*(1-Rf*Sbar)^2` (original Eq12).
3. Otherwise primary loading uses the disclosed positive numerical postfailure modulus `E_failure`. Original1643 describes a small positive modulus;1648 uses an arbitrary10psf for its footing example. The proposed example coefficient is10psf converted using `1 lbf=4.4482216152605 N`, `1 ft=0.3048 m`; it is a numerical choice, not a calibrated soil constant or universal paper prescription. It must be exposed separately from the six soil parameters.

The residuals are

```
sigma - sigma_n - E/(1+nu)*dev(de) - E/(3*(1-2*nu))*trace(de)*I = 0
h - max(h_n,D) = 0
```

The factors follow inversion of original Eq15; Mandel shear stiffness is `E/(1+nu)`. Equality `D=h_n` belongs to primary loading, `Sbar=1` belongs to the numerical postfailure branch, and `D=h_n` in memory selects the active-current expression for a branch Jacobian. These are project boundary choices, not a source claim. The postfailure jump and branch changes can make a finite solve difficult or nonunique; no uniqueness theorem or guaranteed arbitrary-increment solution is claimed.

Accepted subincrements provisionally commit `sigma,h` inside the parent transaction; failed trials preserve their incoming state. A later internal failure that exhausts the parent update rolls back every provisional internal commit to the full external parent input. Retrying that external update starts from the same external committed parent. Max history is updated at accepted internal endpoints. No unimplemented exact event locator is implied. A step crossing a previous maximum or failure threshold uses its selected endpoint branch for that whole subincrement; subdivision therefore matters. Qualification must demonstrate refinement and report partition dependence. Continuation from the zero-increment root is the intended solution selection; an unrelated residual root is insufficient. A zero increment has the identity solution and must return it without artificial history growth. Holds have no physical-time relaxation. Restart requires both persistent fields; no plastic strain/void ratio is invented.

Explicit initialization supplies both fields and complete parameters. Require `h>=D>=0`, finite positive least principal stress, positive `pa,K,Kur,E_failure,p_ref`, `Kur>=K`, `0<Rf<1`, `c_cohesion>=0`, `0<=phi<pi/2`, positive strength denominator and `-1<nu<0.5`. These are prospective project support bounds, not universal published ranges. A hydrostatic virgin example has `sigma=p0*I,h=0,p0>0`; arbitrary nonhydrostatic stress must supply its actual prehistory. Illustrative `pa=101325 Pa` is an explicit SI reference choice. Table1 source coefficients and nu0.3 complex-path example are illustrations, not an experimental validation or a preparation recipe.

These parameter bounds apply on every evaluation, not only initialization. All parameters, including `n`, must be finite; `p_ref` is only a numerical scale and absent from the source law. Every committed and candidate endpoint must have finite stress, strictly positive least principal stress and strictly positive finite Mohr–Coulomb strength; the averaged confinement and strength must also be positive finite before powers/division. Require finite positive selected modulus and finite residual intermediates. Invalid Newton trials report domain failure for the solver's existing retry/rollback machinery; do not clamp confinement or convert a tensile endpoint into an admissible state merely because its average remains compressive. Accepted states must satisfy the memory residual and `h>=D>=0`; intermediate Newton iterates need not satisfy the unsolved memory equation. An exhausted update leaves both incoming fields unchanged. These support/diagnostic choices must survive the eventual declarative domain/solution-constraint and solver qualification.

## Demonstrated generic capability gap

Current numerical `principal_max/min` operations require a simple selected eigenvalue even for primal evaluation. Value-only variants accept repeats but the validator prohibits their numerical use in residuals/history/observables. Standard original triaxial compression has a repeated minimum, extension a repeated maximum, and the hydrostatic initial state repeats both. Pair sums cannot recover both numerical extrema at a triple repeat. Thus the existing Mohr–Coulomb/Tresca branch-grouping solution does not directly resolve this modulus/memory law. This is a concrete executable-expression limitation, not missing source equations and not an excuse to restrict the requested full3D law to distinct spectra.

Run `python3 -B docs/ingestion/duncan-chang-1970/finite-contract-v1/check_capability.py`. [The result](capability-results.json) retains expected failures for the exact source-relevant states and the validator's rejection of a value-only numerical sink. A separate exact directional witness shows why a classical derivative cannot simply be promised: at `p*I`, max eigenvalue along `H=diag(1,0,0)` has derivative1, along `-H` derivative0. A linear derivative would require opposite values. An averaged eigenspace derivative may be a declared generalized/selected derivative, but it is not the classical derivative of the maximum and is not selected by the source. The first diagnostic expected the validator message to say “value-only”; it actually reports a broader shape/dimensions mismatch because type equality includes the dependency qualifier. That failed checker and stderr are retained in [retained-failure-v1](retained-failure-v1/). The corrected check independently confirms matching shape/Pa dimensions and the value-only qualifier before checking rejection; no engine behavior or gate was relaxed.
