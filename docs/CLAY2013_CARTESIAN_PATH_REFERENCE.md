# Independent nonisotropic clay2013 finite-path reference

This research packet advances the existing independently transcribed Cartesian source law with a standalone fixed-step RK4 implementation. It does not call the Atlas DSL, generated model, common integrator, native executable or Wasm. Its sole constitutive dependency is `tools/reference_clay2013_cartesian.py`, whose pinned author-manuscript SHA256 and code SHA256 are retained. This establishes a bounded independent integration reference, not scientific admission or experimental validation. Published/manuscript reconciliation and physical initialization remain separate gates.

The record contains two original paths and their rotated companions: general noncoaxial three-segment loading, and mixed-shear loading followed by reversal and a changed shear direction. All use explicit initial six-component Mandel stress plus e, explicit parameters, and three full six-component caller strain increments. No axisymmetric or deviator-only restriction is imposed. There is zero spin; the rational orthogonal Q is a fixed change of coordinates applied to both stress and all strain increments, not a rotating material frame. Initial stress is strictly SPD and anisotropic. Parameters and state are software fixtures, not a calibration. The caller-segment coordinate is0..1, not physical time; each supplied increment is the complete constant stretching with respect to that coordinate.

At every RK4 stage the independent Cartesian rate performs its own domain checks; each retained endpoint is checked again with zero stretching. Any failed stage aborts generation, with no clipping or regularization. All7 components advance together. Each path is integrated with8,16,32 equal RK4 steps per caller segment; no segment crosses a scheduled reversal. Full initial and segment-end states are retained for every grid. Comparisons use the maximum absolute stress-component difference over all retained rows, and a separate e difference; they do not obscure e using a stress norm.

## Common-engine comparison

`tools/clay2013_nonisotropic_study.py` reuses the existing request/native_call wire adapter. It requests all4 paths at rate tolerances1e-4,1e-6,1e-8, each with3 explicit caller segments. p_scale is fixed to each trajectory's initial mean stress, including the rotated companion. Parameters must match the reference and source p_ref stays fixed1000Pa. Every response's model/parameter/initial/strain echoes, full integration settings and single-model catalogue hash are checked; successful coverage fractions, counters and finite diagnostics must also agree. All7 component errors are retained at each segment endpoint. The stress bound is p_scale times .02/.002/.0002 by tolerance plus1e-5Pa reference budget; e and exact mass-relation bounds are1e-6/1e-7/1e-8. These are declared numerical study thresholds, not physical-model accuracy claims. They may need evidence-based adjustment after the first production run; the original thresholds were retained after the first production run.

Refinement must reduce the path's maximum stress-component error at both tighter tolerances beyond the explicit reference budget. E refinement is not required because pure shear has constant e and the other path's RK4 e differences are roundoff-limited; e's independent mass relation is tested separately. Raw request/response records are flushed after every completed native call, before assessment, so an unsuccessful numerical assessment retains its evidence. A native transport/process failure before a parsed response is outside this raw-response guarantee. The reusable `assess(records,model,reference)` also accepts a Wasm runner's equivalent request/response records; no backend-specific numerical allowance exists. `tools/test_research_matrix_wasm.mjs` replays the matrix with each segment starting from the actual preceding Wasm state; `tools/verify_research_matrix_wasm.py` independently reassesses the resulting endpoints.
