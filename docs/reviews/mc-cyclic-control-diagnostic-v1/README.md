## Independent source discrimination already possible

`check_updates.py` imports only an exact copy of our independently frozen reduced source reference. For each backend, it recomputes the finite source return from observed parent stress and differences of observed cumulative strains. Maximum source-update stress error is8.195e-11Pa on both backends. Subtraction of stored cumulative strains cannot recover the exact unrecorded incoming de; a conservative rounding stress scale is≤9.13e-10Pa. Thus these saved updates are consistent with the source well below the observed µPa path difference, while their selected strain increments differ. This supports distinguishing control-solution drift from a µPa constitutive-update mismatch; it does not prove the precise internal controller cause.

Independent constant-volume q/axial-strain tangents are36MPa elastic,7.101883415MPa compression and4.867029373MPa extension. A strain difference of order4e-13 can therefore produce a few µPa q difference. The source controller probes with h=1e-8: a stress subtraction perturbation of one2.9e-11Pa ulp changes a finite-difference tangent by0.0029Pa/strain (roughly4e-10 relative in compression). This is a hypothesis requiring recorded perturbed states/tangents, not a proven causal chain.
