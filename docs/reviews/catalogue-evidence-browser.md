# Catalogue evidence browser: local verification

The 2026-10-31 local increment advances WEB-01/02/04. It adds shareable `#catalogue/<id>` routes and generates a compact evidence view from retained records, using exact catalogue IDs and explicit research-definition/manifest bindings. It preserves four failed outcomes and three historical definition versions among 17 indexed records. Original envelopes are packaged verbatim; raw numerical reports, binaries and archived source snapshots are excluded from the evidence export. Research definitions are packaged with the existing model tree.

The exporter checks the original artifact receipts. For research manifests it resolves historical source receipts through the existing checked archive API. Current-definition identity is a separate exact byte comparison. A historical definition is never linked as if the current file matched. Numerical outcomes are copied only when an original record states them; missing research outcomes stay unspecified. Literal scope, limitations, flags and further metadata remain accessible. Missing scope summaries are explicit. The generated index lists omitted investigation manifests; source-review envelopes and older unbound manifest formats are outside this increment's coverage.

These checks establish retained-file integrity, not a current solver-binary match, a numerical rerun, independent human scientific review or experimental validity. The browser executable list remains unchanged at five models. Complete formulation assumptions, parameters/preparation requirements, research coverage and benchmark interpretation remain roadmap work.
