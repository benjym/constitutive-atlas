# Clay2014 finite-path transport and pre-observation scope

The finite-path study uses the frozen printed-Eq14 Am/proposed-Eq49 fixed-plane seven-state research definition. It does not select a repair for the source discrepancies, add IGS or plane transport, or admit a public/experimentally validated model. The independent reference, numerical budgets, caller partitions and acceptance criteria are retained in [the reference](clay2014-path-reference.md) and [the frozen design](../../catalogue/investigations/clay2014-path-design-v1/DESIGN.md).

The isolated `atlas_clay2014_solver` CMake target is excluded from default builds. It shares the existing `atlas_clay2014_models` generation command and generated research catalogue. The native target includes the unchanged `cpp/main.cpp` through a generic `tests/research_integrate_driver.cpp` wrapper. Its normal argv interface delegates to the original CLI. `--stream` accepts either `--describe` or five tab-separated fields: model ID, parameter CSV, initial-state CSV, Mandel-increment CSV and integration-settings CSV. It writes and flushes one original C-API JSON response per line. Incorrect transport field counts fail with a nonzero process status. No model-specific dispatch, equations or integration logic is added to the wrapper.

The Emscripten target uses `cpp/main.cpp` directly with the existing exception/link options and separate `clay2014-paths.js/.wasm` outputs. Both native and Wasm collectors must hold one process/instance for the full 295-response protocol: descriptor, 288 chained material updates and three probe/recovery pairs. Native and Wasm prepare their own actual generated parent states. Prefix/control identity, raw transport auditing and unchanged source/artifact receipts are distinct from numerical accuracy checks. Builds are explicit, serial and single-job; public model and browser artifacts are not regenerated by this target.

Before changing CMake, its exact committed previous bytes were archived at `catalogue/source-snapshots/5292c493bf8e55183a453fbab5cf2928f886673e65cbd85f234c9ba4b215ac71/CMakeLists.txt`. A new sidecar binds all three original rate-study receipt documents without altering their bytes or expected hashes. Disposable changed-live, corrupt/missing snapshot and changed-original-document checks passed. `tests.test_clay2014_path_archive` retains these migration regressions. This establishes historical receipt preservation, not a reproducible-build or scientific-validity guarantee.
