## Review and handoff contract

Each packet contains exact formulation/version, source hyperlinks, private source hash, page/equation locators, parameter/state/input table, initialization and unit/sign mapping, unresolved conflicts, and the smallest independent test. Keep copyrighted sources private and record code/data rights separately. Agents stage isolated paths; one owner reconciles manifests, schema, C++ and browser changes. A second run of shared equations is not independent scientific review. Admission additionally requires complete closures, declared initialization/domains, generic-engine compatibility, integration/refinement/rollback evidence, appropriate independent reference/experimental scope and named scientific review. Acquisition or algebra tests alone close none of those final gates.
