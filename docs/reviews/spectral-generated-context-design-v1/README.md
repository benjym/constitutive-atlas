## Failure and rollback acceptance

Primitive checked outputs remain unchanged on failure under their frozen contract. Existing generated evaluate_model and prepare_model_increment scratch vectors may resize or receive partial writes before false is returned; requiring their scratch output bytes to remain unchanged would invent a stronger API. The acceptance condition is that callers discard failed scratch and the accepted solver state, old history and parent data remain unchanged. For history's public transaction API, require unchanged snapshot, no committed events and unchanged generation/preparation counters on failure. Preserve caller inputs in all cases.

For generated Jet calls, inject a nonfinite derivative separately into each of38 columns of an executed spectral operand; each must fail, then an immediate valid recovery must succeed and match its independent reference. The primitive study already covers six primal positions; include at least one generated nonfinite primal and all38 generated columns to prove routing/full validation. An entirely unselected unsupported primitive is not executed; do not require its spectral separation check to fail eagerly.

Sticky tests must force an invalid predicate to appear true using its checked helper's zero fallback, and force a later valid helper execution, then require the entire call false. Do not only test cases where fallback0 naturally makes a domain predicate false, because that can pass while sticky propagation is broken. Eager0*invalid is a runtime failure; value-only0*numeric is a static rejection even though it would cancel algebraically.

Solver rollback requires a failure after an earlier tentative mutation/reset, not only rejection before work begins. Snapshot every persistent accepted state component, old state, reset memory, parent control/time and counters before the call. After failure compare exact stored values/counters and ensure diagnostics identify failure rather than reporting convergence. Then execute a valid request on the same solver object and compare against a fresh solver initialized with the same accepted parent. Retry must not retain sticky flags from the failed call. Fix/declare the solver's residual/iteration/partition policy before compiled observations; this study does not establish MC return-map or nonsmooth tangent correctness.
