# Prospective bounded scalar reference contract

No shared runtime is installed and no generic probe has been built. Passing isolated application observations do not substitute for this independent corpus.

Freeze all exact binary64 inputs before compilation. Use independently constructed Decimal100/160 reference roundings for positive powers and sine. Sine uses Machin pi (converged arctangent series), argument reduction at precision+30 digits and Taylor series; power uses Decimal noninteger power, with converged precision as evidence rather than formal correctly-rounded proof. For every finite reference, including subnormals and rounded zero, require error <=1ULP of its correctly rounded binary64 reference (minimum-subnormal ULP at zero). Infinity/NaN classification and zero sign are compared separately, never by JSON number equality. These are bounded corpus accuracy claims, not universal math guarantees.

Jet smooth positive-base corpus compares base derivative b*a**(b-1) and exponent derivative a**b*log(a) independently at100/160digits. Require precision convergence and each error <=2e-300+2e-14*abs(reference), componentwise, including zero references. The accepted bound is fixed before new compiled observations. Independently inspect inactive derivative lanes: they must stay finite positive zero, including scalar-value overflow/domain cases, as required by the existing conditional skip rule. Negative-base integer powers with inactive exponent lanes receive explicit base-derivative checks; activating the exponent lane retains original log-domain NaN. Zero-base singular examples preserve original classification instead of claiming a smooth tangent. Include signedzero and nonfinite scalar cases with explicitly frozen expected classifications/signs.

Compiled scalar probe returns each scalar as {classification,signbit,value_if_finite}, plus all38Jet derivative lanes for Jet calls. Run the same exact corpus against native and Wasm with all invalid/nonfinite cases retained. Shared-backend equality is additional evidence only; both must independently satisfy references/classifications. Current supported build contract is GCC/Clang/AppleClang/Emscripten binary64/evaluation-width0 with default nearest rounding and actual -ffp-contract=off commands. Alternate modes/compiler families are not admitted by this task. No policy/budget/case removal after observing results.

All prior standard14/native/recorded/strict, Duncan material/API, generic regression and package/browser gates remain independently required as stated in PLAN.md. Existing raw failures and receipts stay unchanged.
