# Barodesy body-law independent caller-point reference packet

Additive independent reference only. Eight supplied paths, each with three original segments, are evaluated at caller partitions 1 and 7. This retains 208 states including 16 original initial states, or 192 accepted reference updates. No generated material state is an input to either reference.

The six scalar paths carry the signed exact isotropic solution at 100 and 160 Decimal digits. The two full-tensor paths carry independent Cartesian seven-state RK4 on three meshes through every actual caller piece. Nominal physical meshes match between partitions; binary64 residual pieces mean actual steps may differ. The frozen evidence includes actual steps, last-pair uncertainties and initial stress scales. Uncertainty estimates are empirical, not rigorous error bounds.

`tools/reference_barodesy2017_caller_points.py` imports the installed `tools.reference_barodesy2017_wider_paths` reference. Public API: `split_path(increments, partitions)`, `scalar_case(case, partitions)`, `tensor_case(case, partitions)`, `fixed_scale(initial)`, `eligibility(stress_difference_pa, void_difference, scale)` and `study()`. Point state keys are `state160` for scalar and `state` for tensor; points include the original initial at index zero. Every update point records its actual increment, original segment, caller piece, original-endpoint flag and exact accumulated strain as Decimal strings. Binary64 splitting/accumulation uses exact rational arithmetic and rejects a nonrepresentable residual.

Fixed stress scale is max(1 Pa, hypot(*original_initial_stress6)). Predeclared scaled stress budgets are [0.005, 0.0003, 0.00002]; absolute void budgets are [0.00005, 0.000003, 0.0000002]. Reference eligibility requires separate stress and void uncertainty at most one tenth of their smallest respective budget. All current scalar rounded 100/160 values coincide; maximum retained tensor last-pair stress difference is approximately 1.7932e-7 Pa, void difference 3.34e-16.

Validation: 14 pure Python tests passed, including frozen evidence equality, scalar eligibility corruption, exact wide binary64 cumulative transport and tiny increments. Frozen evidence generation and tests each take about five seconds. Install the module/tests/protocol/reference at their existing relative paths. No model, compiler, solver or authoritative repository edits are included. No native/Wasm execution, source admission or physical validation is claimed. The body-law source/version limitations remain those of the baseline wider reference packet.
