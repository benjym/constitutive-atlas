# Eight-path Barodesy research integration protocol

This collector and assessor exercise the unchanged common seven-state zero-spin body-law solver. They do not grant public model, full material law, experimental, finite-spin or tangent admission. Source choices and unresolved Appendix/body discrepancies remain those in the [source packet](barodesy-clay-2017-source-packet.md) and [implementation checklist](../models/barodesy2017-implementation-checklist.md). The independent [caller-point reference](barodesy2017-wider-caller-reference.md) carries original supplied states rather than generated solver states.

The matrix has eight paths, three original segments each, tolerances 1e-4/1e-6/1e-8 and caller partitions 1/7. It contains 48 trajectories and 576 actual updates. Six scalar paths cover three soils with off-NCL compression and reversal/reloading. Two tensor paths cover nonproportional loading and its rotated companion. All original reversals retain their order; no sorting by strain or generated-state reference restarts occur. Actual partition residuals and cumulative binary64 inputs come from the exact-rational reference splitter.

Every caller point compares all six Mandel stress components through their Frobenius error divided by the fixed original initial stress norm (at least 1 Pa). Bounds are 5e-3, 3e-4 and 2e-5. Separate absolute void-ratio bounds are one hundredth of these. The comparator adds 1e-7 Pa/1e-14 void floors and the separately retained empirical reference uncertainty: scalar 100/160-digit difference or tensor final RK4 pair difference at that point. Reference uncertainty must be at most one tenth of the smallest corresponding budget. These are empirical estimators, not certified error bounds. Independent exact incompressible-grain void closure is checked separately using Decimal accumulated loading from the original initial state.

For each path at each partition, endpoint errors must contract by 0.65 successively and 0.35 overall, allowing twice the floor plus maximum observed reference uncertainty. Differences between production caller partitions must contract by 0.35 from loose to tight tolerance, allowing twice the floor only. Native/Wasm state and initial-parent differences must be at most 5e-11 in the fixed stress scale or absolute void ratio. These gates are declared before compiled observations and cannot be relaxed to turn an observed failure into success.

Transactions use the first tensor path at tight tolerance and caller partition one. Its first two actual successful matrix updates form the committed prefix. The actual third update is the recovery control. From that same committed second state, the study requests the third update with substep budget three (must fail after accepted internal progress), [0.9,0.9,0.9,0,0,0] (domain failure), and exact zero loading. Failures must return the exact committed parent. Zero must preserve it. Each probe is followed by the identical control request and must reproduce its complete response. The seven-state model has stress and void ratio; this checks material-state rollback, not separate strain or history memory.

Native and Wasm collectors persist opaque transport before parsing/status/acceptance checks and checkpoint parsed responses before accepting them. There are 583 transport rows: one descriptor, 576 matrix updates and six probe/recovery calls. The independent transport auditor binds every raw request and parsed response, native argv and exit status, and Wasm C ABI argument list. Native/Wasm numerical parity binds the exact retained native report bytes and audits both explicit transport companions. Report identity binds the current Python study and Node collector bytes; external manifests additionally pin source/build artifacts. Portable historical assessment accepts explicit file paths, with no absolute temporary path embedded in the report. Source/build artifact manifests remain separate evidence receipts.

Run from the repository after installing the independent caller reference and without changing the existing solver:

```sh
python -m tools.barodesy2017_wider_study --solver /path/to/atlas_barodesy_solver --output /path/to/native.json
node tools/test_barodesy2017_wider_wasm.mjs --native-report /path/to/native.json --wasm /path/to/atlas_barodesy_solver.mjs --output /path/to/wasm.json
python -m tools.barodesy2017_wider_study --report /path/to/wasm.json --transport /path/to/wasm.transport.jsonl --native-report /path/to/native.json --native-transport /path/to/native.transport.jsonl --output /path/to/wasm.assessed.json
```

For historical native reassessment use `--report`, its explicit `--transport`, and `--output`. The collector retains failed raw runs as negative evidence. A failing predeclared gate is a failed study, not an instruction to alter the gate. The synthetic unit tests exercise corruption handling and do not stand in for actual native/Wasm observations.
