## Independent scalar isotropic check

Only when all anisotropy ratios equal1 and the initial stress/loading are hydrostatic does the scalar reduction apply. The selected fixture uses `nu_pp=0` to preserve equal Cartesian diagonal arithmetic without injecting an artificial isotropic projection. The exact spherical source branch has `Fm=0`, source direction `-I/sqrt(3)`, and `fd/fdA=(p/pe)^a`, where `a` is the proposed positive Eq49 exponent. Let `v` be signed compression volume strain, `s=sign(dv)`, `c=(1/kappa-1/lambda)/2`, and `y=(pe/p)^a`. Then

`dp/dv = p/2 * [(1/lambda+1/kappa) + s*(1/lambda-1/kappa)*(p/pe)^a]`,

`dy/dv = -a*c*(y-s)`,

`y_new = s + (y_old-s)*exp(-a*c*Delta_v)`,

`pe(v)=pe_initial*exp(v/lambda)` and `1+e(v)=(1+e_initial)*exp(-v)`.

The implementation evaluates the first update as `y+(y-s)*expm1(...)`, requires finite positive `y` and permitted `e`, and composes through each actual caller piece. The real solution is analytical; its implementation is binary64 evaluation, not correctly rounded or arbitrary-precision certification. Exact Fraction volume receipts are rounded only when evaluating transcendental functions. Unloading generally does not follow a universal exact kappa slope away from its appropriate state. The scalar formula was independently rederived by a second reviewer and is tested against the full Cartesian RK4, caller composition, both loading signs and the rate derivative.
