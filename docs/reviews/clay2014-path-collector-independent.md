## Findings resolved before observation

The first native draft spawned separate processes and could not substantiate native same-process recovery. It also overwrote existing raw/report paths, took a late binary hash without an end guard, and checked only SPD/e rather than the full returned source-domain restrictions. The reviewed version uses a single NativeSession, fresh-output rejection, before/after binary binding and independent full source-domain checks.

A `select` followed by blocking `readline` did not bound a partial-line stall. The final stream reader uses deadline/select/os.read framing, journals partial opaque bytes and their hex on timeout/EOF, and drains termination output with communicate/kill. A later write error could have attributed the previous response to the next request; resetting the partial buffer before each write and a dedicated regression resolve that attribution error. Parsed responses are checkpointed before acceptance; malformed responses and exceptions remain raw retained evidence. The exit status/stderr/trailing output are separately retained, and invalid termination cannot pass full assessment.

The first parity implementation verified an in-memory native report and separately checked a file hash without proving that they were the same document. The reviewed version holds one file byte buffer, hashes/parses it and compares the parsed object to the supplied native report before assessment; it guards report/raw files against change after assessment. Raw transport verification similarly hashes and parses the same held bytes. Both explicit raw companions are independently audited against all295 request/response rows, rather than merely accepting a recomputed companion hash. Archived assessment requires a fresh output distinct from every input.

The independent repo-ready regression constructs complete native and Wasm295-row companions and first passes parity. It then corrupts each raw companion's parsed state, deliberately rebinds all affected report/file hashes, and still requires rejection of the semantic raw-response mismatch. It also supplies an unrelated native file with a newly matching Wasm receipt hash and requires rejection of the in-memory/file mismatch. It performs no compiled call.
