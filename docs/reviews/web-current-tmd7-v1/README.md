prediction to a traceable current native build. A separate panel displays the
TMD7 compatibility outcome, all seven gate values/limits, per-engine diagnostic
counts, descriptive experimental errors, source/build identity and two evidence

## Binding and privacy

`tools/build_propagation.py` checks public packet hashes and binds the current
TMD7 result to its frozen policy, archived prediction identity, calibration-only
selected vector, current build receipt and built model hash. It recomputes all
seven compatibility predicates and verifies recorded saved-reconstruction status.
The exporter does not open private experiments, raw process receipts or the
independently owned paper tree. This website check does not independently
reconstruct private native observations; that evidence remains in the
[replay packet](../../benchmarks/current-kfs-tmd7-v1/README.md).

[Public scalar projection](public-summary.json) is constructed field by field.
Private paths, commands, parameter/state/point arrays and acquired coordinates
cannot enter through unused result fields. Hash substitution, changed artifact,
false gate and scientific promotion checks reject; a consistent failed gate
remains valid, visible evidence.

Six exact historical source files were preserved before editing, using the
[prior view's archive map](../web-kfs-propagation-v1/source-archive-map.json).
Both earlier website manifests still verify without rewriting their original
pins or outcomes.
