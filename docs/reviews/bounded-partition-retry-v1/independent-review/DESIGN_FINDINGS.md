# Independent bounded partition retry design findings

Reviewer: actual independent run `/root/spectral_multiplicity_review`,2026-11-01. Prospective review only; no production changes, compilation or material update executed. Decision: **the bounded search idea is reasonable, but clarify the diagnostics and tangent interface before design acceptance**.

The retained full native material assessment is a failure with twelve assertions originating from four incomplete loose max-history paths/restarts. The separate independent source analysis demonstrates branch-inconsistent unsplit residual roots and constructs admissible alternative subdivisions. I read its exact input-bound results. A single generic1/3 then2/3 retry is a legitimate bounded partition-search heuristic; it does not inherit a source guarantee that those particular fractions succeed. It must retain all original success expectations, physical/reference budgets and failed observations.

Successful original trajectories must run first unchanged. Retry must occur only after the ordinary incremental integration attempt fails, after input/parameter/domain/reset preflight has succeeded. It starts from the original prepared parent, without reusing failed tentative history or repeating external preparation. Rate-law behavior stays unchanged. A single alternate root split plus ordinary dyadic recursion below its depth1 children is bounded, provided both attempts share accepted-tentative-work budget and the original maximum depth. Iteration/backtracking limits remain per existing implicit solve. No reset of spent work or increase of budgets is permitted.

Clarify total-failure diagnostics: if `substeps` and fractions describe committed work, a failed external parent has zero committed steps and all accepted tentative work is discarded. Alternatively retain the old tentative-on-failure convention explicitly, but do not present such fractions as a committed path. `attempted_substeps` must control the global budget independently of counters later reset to describe the accepted retry path. Iterations/rejections must retain both attempts. Public diagnostics must distinguish all these identities.

The root binary split guard should reject any nonzero incoming component lost to a zero child, nonfinite child, or rounded recomposition unequal to the incoming component. Exact TwoSum defect and a safe scaled bound disclose the real-sum discrepancy even when rounded recomposition succeeds. Tiny/subnormal inputs need independent exact rational checks; a floating underflow in the bound must not silently classify an unacceptable defect as zero. Actual accepted loading values, not only nominal fractions, are necessary for audits.

There is an additional interface dependency: `linearize_update` currently reconstructs every accepted subincrement as `Jet(fraction)*total`. The proposed division/remainder split is generally not bit-identical to nominal-fraction multiplication, so fractions alone no longer specify actual primal loading for replay. This can alter branch/history even if a final endpoint comparison happens to tolerate the discrepancy. Record actual accepted subincrement tensors or an exact split-operation transcript and replay their primals, with explicitly declared frozen-partition derivative seeds; alternatively explicitly reject tangents on fallback until supported and qualified. Do not silently return a tangent for a different partition. This needs a separately explicit scope/whitelist and prospective test. Clarify whether the derivative is the declared idealized fixed nominal partition or AD through the floating split operations; those are not automatically identical.

Required frozen gates: all unchanged full Duncan material/API requests and independent references, retained forced-failure budgets, restart/recovery, original13-model regression, previous81-request solver and219-case/12-step Tresca qualification; additionally analytical alternate-success/no-root witnesses, consumed-work exhaustion, depth0, tiny/underflow/nonfinite split guards, exact fractions/defects, discarded/committed accounting and tangent replay behavior. Successful original requests must not use retry. Numerical parity is supplementary to independent source/reference checks. No E5 or broader delivery inference follows from generic qualification.
