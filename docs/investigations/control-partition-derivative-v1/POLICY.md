# Prospective design and implementation qualification policy v1

Frozen before proposed implementation or new compiled observations. This policy does not alter any MD1997 source or numerical acceptance gate. Design-only worker executes no compiled code.

1. Pure source-derived/synthetic tests of helper semantics: different counts; equal counts/different ordered fractions; incomplete actual increments; invalid/nonfinite metadata; dyadic and non-dyadic affine audit including zero/negative/shear channels; unmatched probe never used. Coverage finite positive and unit-sum convention must be enforced.
2. Synthetic adaptive-map counterexample: base one-step smooth slope78MPa; original positive perturbation selects two-step map with an offset yielding a wrong-sign raw difference. h/2selects base partition and recovers source slope to roundoff. Bounded exact-boundary case must fail after11probes with no accepted derivative, preserve original parent state, and make no unmatched derivative claim.
3. Protocol3 directional analogue [1,-.5,-.5,0,0,0] with same map counterexample; verify denominator uses selected h. This is structural source evidence, not an assertion of a previously observed protocol3 failure.
4. Exact old MD1997 frozen coarse-control initial-state fixture and full original128/512path requests: unchanged parameters, bounds, settings, constitutive model hash, source references and all stress/alpha/void/refinement gates. The operational regression requires completion of the former failed coarse path. Numerical source-gate failures remain failures; this generic fix cannot waive BE truncation. Preserve original failedtrace and compare newtrace; no material-specific fallback.
5. Existing full ordinary native/Wasm compatibility/regression and generic mixed-control tests must pass under coordinator-owned serial builds. Native/Wasm execution belongs to parent after independent design review/implementation authorization. Include feasible/infeasible final-solution constraints, initial-state validation and rollback on probe exhaustion or inner failure.
6. Parent must record bounded probe counts, selected h, partition comparability and exact outcome in diagnostic evidence. Extra calls cannot change accepted material state or hide failed probes. No changed control tolerance, max_depth, max_substeps, max_backtracks, outer iteration cap, or model constants.

No synthetic success alone approves the implementation. If the exact regression still fails, retain it and open a separate fixed-partition replay/analytic-control capability rather than expanding this patch without review.
