Historical `checked_receipt` allows a receipt's original path/hash pair to resolve through its exact document pin, unambiguous sibling map and verified canonical bytes. It never recomputes a receipt's expected hash, accepts a corrupt archive or falls back from one to current source. That machinery preserves the meaning of old evidence. It cannot qualify a new runtime artifact.
