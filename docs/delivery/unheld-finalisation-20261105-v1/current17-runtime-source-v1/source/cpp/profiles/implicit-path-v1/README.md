# Versioned generic implicit strain-path engine

This profile preserves the generic residual, adaptive implicit step-doubling,
positive-stress error metric and outer-control initialization qualified for
Lade–Duncan 1975. Constitutive expressions are generated by the normal Atlas
compiler. There is no handwritten Lade material kernel. Current unversioned
common-engine repairs remain separately owned and qualified.

The ordered build corpus includes the exact public Lade definition and three
historical regression witnesses. Only Lade may be exposed through the public
profile route. The full compiled catalogue remains available for identity
checking; witness inclusion is not scientific admission.

`tools/generate_implicit_path.py` uses canonical inputs and rejects generated
header/catalogue drift. `cmake/implicit-path-v1/` maintains native and Wasm build
recipes. Builds require a coordinator's serial slot, one explicit
`atlas_implicit_path_v1` target with `--parallel 1`. A newly built artifact has
no automatic qualification receipt. Packaging must use independently reviewed
source, model and actual artifact identities; matching source alone does not
approve a new binary.

The original exact runtime and all failed studies are retained under
`docs/ingestion/lade-duncan-1975/`. Scientific, interface, browser and live
qualification remain separate gates in that model's delivery ledger.
