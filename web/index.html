REPRODUCIBILITY BEFORE RANKINGS

Every claim needs evidence.

An executable model is the start of verification, not the end of validation.

01 / REPRESENTATION

One mathematical source.

Restricted scalar and symmetric-tensor expressions are dimension checked, interpreted in Python, and compiled into C++. Model definitions contain no native code. The browser executes the generated kernels through Emscripten.

SI units. Compression-positive stress and strain. Mandel order: xx, yy, zz, √2xy, √2yz, √2xz. Infinitesimal kinematics, zero spin.

02 / NUMERICAL VERIFICATION

Test equations and algorithms.

Analytical elastic tests, yield consistency, hardening and unloading, step refinement, small-strain stiffness, automatic-differentiation Jacobians, and interpreter/native/Wasm agreement. Failed steps retain the last committed state.

03 / EXPERIMENTAL VALIDATION

Keep calibration separate.

Published parameter baselines precede controlled calibration. Entire tests are assigned to calibration or held-out sets. Comparison requires compatible material, preparation, initial state and loading conditions.

This release makes no experimental ranking claim.
