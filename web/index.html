EQUATIONS · ASSUMPTIONS · EXECUTION

      
A common language for constitutive models.

      
Atlas expresses constitutive models as structured mathematical definitions. Equations, material parameters, internal state and physical conventions live together, so the same description can be inspected, checked and used to generate an executable model.

      

        Published formulation→Explicit model definition→Shared solver→Material response
      

      

        
01 / THE MODEL RECORD
          
Describe what makes the model.

          
A schema specifies the structure of each definition. Named parameters carry units and bounds. State variables record stress and material memory. Derived quantities and governing equations describe how that state changes; domain conditions declare where the expressions are admissible.

          
Source links and locators identify the formulation being represented. A model family, a later extension and a particular parameter set have distinct identities.

          
Explore the model definitions → · Trace publications and extensions →

        

        
02 / PHYSICAL MEANING
          
Make the conventions explicit.

          
The same symbols can mean different things across publications. The v0.3 formulation contract declares stress measure and effective/total scope, stress and strain signs, tensor representation, kinematics and frame assumptions.

          
It also distinguishes an incremental equation, a rate along a strain path and a rate per second. Required loading inputs and initialization requirements are explicit: choosing a strain increment does not imply a physical duration, and an illustrative state is not a material preparation procedure.

A SMALL EXAMPLE / ISOTROPIC ELASTICITY
          
Give an equation its context.

          
For an infinitesimal elastic strain increment, the stress update can be written as:

          
Δσ = K tr(Δε) I + 2G dev(Δε)

          

            
Parameters
Bulk modulus K and shear modulus G, both in pascals; they may be derived from Young’s modulus E and Poisson’s ratio ν.

            
State and input
Stress σ is retained between increments. The supplied strain increment Δε is dimensionless; I is the identity tensor.

            
Conventions
With compression positive, a positive isotropic strain increment raises compressive stress. Tensor storage and stress scope must also be declared.

            
A checkable consequence
For Δε = aI, the deviatoric term vanishes and Δσ = 3KaI. This gives an analytical reference for an isotropic loading test.

          

          
The schema gives these ingredients named places. The expression language describes their mathematical relationships.

03 / EXECUTION
          
Separate the equations from the solver.

          
Atlas uses a restricted language of scalar and symmetric-tensor expressions. The definitions describe the mathematics rather than embedding a separate handwritten implementation for each model.

          
After validation, those expressions can be evaluated in Python and compiled into C++ for the shared integration engine. The browser runs generated kernels through WebAssembly. Loading protocols, numerical integration and failure handling belong to the surrounding solver.

          
A shared representation makes formulations easier to inspect and exercise under common loading conditions. Each still needs its own parameters, initial state and applicability checks.

          

        

        
04 / VERIFICATION
          
Check structure, mathematics and behaviour.

          
Automatic validation checks required fields, declared symbols, expression types and dimensional consistency. These checks can detect an undefined variable or incompatible units before a simulation runs.

          
Numerical evidence addresses different questions: agreement with analytical solutions, response to smaller steps, and agreement between Python, native and browser execution. Available checks and their scope are recorded per formulation.

          
A dimensionally correct equation can still be the wrong transcription. Agreement between implementations can preserve the same mistake. Source review and independent references remain necessary.

        

        
05 / SCOPE
          
A common structure, with explicit limits.

          
The v0.3 contract currently supports incremental residuals, strain-path rates and physical-time ordinary differential equations within declared small-strain, fixed-frame profiles. Finite-deformation transport and objective stress-rate updates are outside those profiles.

          
When a formulation needs an unsupported input, tensor type or history mechanism, that is a capability gap to resolve. A catalogue entry does not by itself imply an executable or reviewed model. Existing records retain their versioned definitions while migration proceeds.

          
Inspect schema v0.3 (JSON) →

        

        
06 / EVIDENCE
          
Keep claims attached to their evidence.

          
Source transcription, executable availability, numerical verification and experimental validation answer separate questions. Each result needs a formulation identity, inputs, protocol and a stated scope.

          
For measured-data comparisons, material preparation and initial state matter alongside the equations. Calibration and evaluation must be distinguished; previously inspected development tests do not become unseen validation data.

          
This release makes no experimental model-ranking claim. Model details in the catalogue link retained numerical records, including limitations and failures.

Does Atlas recover the published model response?

            
The TMD2 study uses VW96 with intergranular strain for loose Karlsruhe fine sand at 100 kPa. Three native resolutions over 0–25% accumulated axial strain agree with published model curves within frozen figure precision; adjacent refinement checks pass.

            
This is a published-calculation reproduction. Measured-data errors belong to the calibration campaign; historical strain conversion and independent scientific review remain open.
